# 07 叶幕走廊：在这一面，修好另一面的路

工程：`UnityProject-NOVA-URP`，场景：`Assets/Scenes/SeventhTrellis.unity`。继续使用 Unity 2021.3.42f1c1、URP 和既有灯芯精灵骨骼模型、NOVA 头部火焰。

工作区根目录双击 `试玩第七关.cmd` 可直接进入第七关；双击 `打开第七关工程.cmd` 可在 Unity 中打开本工程和场景。也可以在 Unity Hub 中添加本目录。现有 Windows 包包含第一至第七关，第六关完成后按 E 进入第七关。

## 操作

| 输入 | 作用 |
|---|---|
| A / D | 实体移动；光态沿同一光路前后移动；抓住镜车时推车 |
| 空格 | 跳跃；跳过开场全景 |
| E | 实体操作机关、抓住/松开镜车；光态在安全落脚处恢复实体 |
| 站光 3 秒 | 站稳、停止移动后化为光粒子 |
| Tab | 全景与跟随镜头切换 |
| R | 重开本关 |

恢复实体后先走动一下，再站回光里充能。推车期间不会自动化光。前后面不是按键自由切换：必须沿光穿过实际镜窗；镜头过渡时暂停操作，保持光态。

## 两个机关的区别

- **K背：背面高处机关**，展开正面三片育苗踏阶，状态锁止保留。
- **K前：正面高处机关**，放下背面轨桥并卷起背面挡叶，状态锁止保留。

正面厚叶墙始终阻挡通路，它与背面卷帘不是同一片障碍。镜车只有一辆，R0、R1 是它的两个停靠位置。

## 通关路线

1. 正面入口走到 P 镜窗来光里，三秒化光，沿光穿到背面 Q，恢复实体。
2. 在背面沿三片固定跳台爬到 K背，操作后看到正面踏阶展开，再回到背面安全地面。
3. 镜车仍在 R0 时，站低处光束化光，经镜车旁的镜窗返回正面 R0。光在附近的终止罩结束，不会送到高处机关。
4. 实体沿正面已展开的三片踏阶跳到 K前，操作后背面轨桥放下、挡叶卷起。原路回到正面 R0 的低处来光。
5. 化光沿原路逆向回到背面，恢复实体，E 抓住镜车，沿轨桥推到 R1，再 E 松手。
6. 松车后在低处来光里停稳三秒化光，经 R1 穿回正面厚叶墙后，恢复实体。唯一光路持续照亮浅白背侧的目标灰鳞两秒后，出口开放，向右完成本关。

镜车停在轨道中间时，背板没有镜窗，光不能穿到正面；可在背面落地后继续推车或推回。桥未开时车会在缺口前止住。失足会回到当前面有来光的固定安全台，保留两个机关及镜车位置。

## 美术与场景组织

前后两面使用同一组世界横向坐标和地面高度，以镜窗对应关系连接。每面分别包含：

- `01_Background_NoCollision`：清理掉玩法物体的淡水彩温室后景。
- `02_HorizontalPlatforms_Collisions`：水平岸台、独立跳台、叶墙/叶帘和场景碰撞。
- `03_ReusableProps_Mechanisms`：独立镜窗、镜车、桥、卷帘轴、拉杆与有固定点的连接绳。

第六关的园艺预制体继续复用；新增构件保存在 `Assets/Prefabs/TrellisReusable`，本关纹理在 `Assets/Art/Level07`。原始分层图片和生成提示词在工作区 `art/level07-unity-assets-v01-2026-11-05`。

背景、水平平台和交互道具可分别编辑，光束与联动不烘焙在图片中。场景镜头是正交侧视；装饰支架不提供额外跳跃捷径。只启用角色所在面的物理碰撞，机制预览期间暂停人物模拟。

## 光路与程序

`SeventhFaceLightPath` 将正面 S→P、背面 Q→镜车、正面 R0/R1→终点组成同一条有顺序的光路。两个穿架段具有独立的纵深行程，不画成两面之间的巨大横线。充能只读取当前面的光，镜窗过渡保留化光状态、方向与路径位置。

`SeventhTrellisFlow` 管理机关锁止、镜车限制、前后面显隐、预览、复活和通关；`SeventhFaceCamera` 管理全景、跟随与穿窗遮罩。前六关不使用新的纵深路径，其原有光路行为保留。
