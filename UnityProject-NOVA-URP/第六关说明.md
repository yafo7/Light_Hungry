# 06 温室苗床：途中落脚，往返换位

第六关已在 `UnityProject-NOVA-URP` 内搭建，并有 Windows 原生试玩。它使用一束光：先借光到达右岸，降下育苗托盘；回程途中恢复实体，落到托盘开帘；再返回右岸升盘，将同一托盘改作上层接光节点。

**操作与正常路线**

| 操作 | 作用 |
|---|---|
| A / D | 实体左右移动；光态沿当前光路前后移动 |
| 空格 | 实体跳跃；开场时跳过全景展示 |
| 站在有效光中静止 3 秒 | 身体逐渐发光，然后化为光粒子；需要站稳，不能在空中充光 |
| 光态 E | 下方短距内有安全落脚面时，在当前位置恢复实体，再由重力落下；没有安全落点或空间不足时保持光态 |
| 实体 E | 操作附近机关；调镜时再次按 E 松手 |
| W / S | 握住调镜手柄时切换镜向档位；C 镜需要观察出射光是否对准窄孔 |
| Tab / R | 切换全景 / 重新开始本关 |

恢复实体后，先走动一下，再站回光中静止，可重新开始 3 秒充光。托盘升降期间等待机关锁止，再继续操作或充光。实体才能操作机关，光态只能沿现有光路移动。

1. 在左岸 A 化光，沿下层光到右岸 B。恢复实体后，E 操作卷轴，将 P 托盘降到低位。
2. 在 B 重新化光，沿原光向左返回；到低位托盘左侧、K 绳扣上方时按 E，恢复实体并短落到托盘。
3. 站稳后 E 操作 K，遮光帘 G 卷起并保持打开。走到托盘右侧，通过两级固定小搁板回到光束高度，重新化光去 B。
4. 在 B 升回托盘。等待停止后，再沿下层光返回 A。A 手柄 E 握住，W 切换到上层，E 松手。
5. 化光到 C 玻璃台，恢复实体，操作 C 手柄，让光穿过遮光板窄孔。高位 P 的固定镜片将光转交给 D；可在高位托盘落脚，也可继续沿光前往 D。
6. 到 D 恢复实体，操作末镜照向灰暗肋鳞。持续受光约 2 秒后鳞片亮起、出口根帘打开，走到右侧完成本关。

如果先把 A 改向上层而 G 未开，光会被帘挡住，可以退回 A。如果开帘后忘记升 P，C 的光穿孔后会停在右挡板，仍可退回 C、A，改回下层去 B 修正。两个错误状态都保留返程。

**场景实际如何分层**

背景、平台和机关是分离的。当前使用正交摄像机；平台美术是正对摄像机的水彩贴图平面网格，水平碰撞面另行配置。主角使用已有骨骼 3D 模型，移动与碰撞按 2D 平台游戏处理。

| Hierarchy 中的根对象 | 内容与职责 |
|---|---|
| `01_Background_NoCollision` | 柔化、减淡后的温室后景；没有可行走碰撞 |
| `02_Horizontal_Foreground_Collisions` | 两岸苗床、上层玻璃台、回光阶、遮光隔板，以及对应场景碰撞体 |
| `03_Reusable_Interactive_Props` | 托盘、四处镜子、手柄、卷轴、滑轮、绳索、遮光帘、食光兽肋侧、目标鳞与出口；光束渲染对象也在此组 |
| `WickSpirit_Player` | 真实 3D 主角及 2D 控制、碰撞、化光能力 |
| `ONE_Source_EffectiveOpticalPath` | 当前唯一有效光路；根据机关与遮挡结果更新 |
| `SixthGreenhouse_CombinedPuzzle` | 本关机关状态、交互、复活点、通关判断 |
| `Main Camera` | 正交全景与跟随镜头 |

玻璃台支持实体落脚、允许光核穿过；实体墙与不透光隔板会截光。悬吊托盘的碰撞体随托盘移动，两级回光阶固定在沟壁，不跟着托盘升降。
