# Light Hungry｜关卡策划指导案 v0.4

更新：2026-11-03。用途：程序与 Zoe 搭建关卡时核对玩法、道具和状态。

依据：`light.excalidraw`、`light_3d.excalidraw`。图中的重复 Level 4 按同关不同状态理解；两处 Level 6 暂编为第 6、7 关，不代表新增关卡。具体尺寸、命名与最终解法仍以试玩确认为准。

## 1．统一规则

| 项目 | 本版规则 | 状态／边界 |
|---|---|---|
| 核心体验 | 用光移动、改造光路；通过平行面绕过单面无法通过的障碍 | 第 1～4 关面内；第 5～7 关主要为 A/B 平行面，不强行增加四面关卡 |
| 移动 | A/D 移动与推动；W/S 上下观察；空格跳跃 | 实体受地形阻挡 |
| 交互 | E 单次触发开关；持续 E 转镜、拉绳 | 镜子是否限制角度，按关卡单独确定 |
| 化光 | 连续受光 2 秒后化光；默认速度 11，约为步行两倍；空格提前恢复并跳出 | 实体占用空间不足时拒绝恢复；跨面途中不能在两面之间凭空恢复 |
| 光强 | 数值更高的面内光束能在交点接管光团；同强度不接管 | 默认均为 1；强弱对应的美术表现尚待确定；光强不改变速度或喂食速度 |
| 普通镜 | 反射本面光，不接收跨面光 | 不同面的镜子不能因坐标重叠相互影响 |
| 黑镜／深度镜 | 按真实位置和法线将光射出平面；接收黑镜将其反射回所属面的平面 | 不瞬移、不按镜头方向猜面；斜射可改变另一面的落点 |
| 接收平面／光斑 | 跨面光命中指定接收平面形成光斑；光团可在有空间时恢复实体 | 属于新关卡要求的抵达能力；光斑不是可直接照野兽的平面光，仍需黑镜接光 |
| 玻璃／栅栏／透光平台 | 阻挡实体，允许光与光团通过 | 透明外观不自动代表改变方向 |
| 透镜 | 可设置固定角度偏折与宽度倍率；偏折 0 表示直通 | 为风格化玩法规则，不模拟真实介质、聚焦或水面折射；第 3 关是否需要偏折待定 |
| 滑轮 | 持续拉绳上升，松手下降；可逐个开启“升顶锁定” | 默认维持旧下降规则；第 1 关建议锁定，是否采用待确认 |
| 野兽 | 积累受光至吃饱；可作为机关输入或触发事件 | 中途野兽不直接结束带出口的关卡；吃饱后的运动、对白、发光另行绑定 |
| 完成条件 | 有出口：进入出口且满足其前置条件；无出口：兼容原目标野兽通关 | 下一关名称留空只提示完成，不自动切关；填写构建列表内 Scene 名可切关 |
| 显示与碰撞 | 稳定视角仅显示本面；实体不与其他独立面的物体碰撞 | 明确共享的对象可参与多个面；隐藏不停止机关逻辑 |

## 2．关卡总表

| 关卡 | 目标／学习点 | 主要流程 | 所需道具 | 核心状态变化 | 离开条件 |
|---|---|---|---|---|---|
| 1 · GO DOWN | 认识推动、反射、喂兽、化光 | 推箱越门 → 推镜接阳光喂兽 → 拉起滑轮、导光到排水口 → 化光进入 → 撞内壁恢复并下落 | 箱子、门／墙、阳光、普通镜、野兽、滑轮、排水口 | 门外 → 花园；饥饿 → 吃饱；排水口无光 → 可进入 | 进入地下入口；野兽吃饱是中途事件 |
| 2 · UNDER DASH | 利用光穿越障碍；理解强光接管与主动退出 | 缝隙光出发 → 调镜穿过水面／管道 → 被强手电筒带向上 → 利用顶部光重新出发 → 空格避开另一束光 | 漏光口、普通镜、手电筒、管道、坑／水面、落脚点 | 水平旅行 → 强光转向；光团 → 实体 → 再化光 | 到达竖井入口；水面失败规则待定 |
| 3 · UP UP | 组合喂兽、显现平台与竖向光路 | 调镜喂兽 → 显现透光平台 → 重组向上光路并停靠／再出发 → 顶部推门离开 | 顶部光源、普通镜、野兽、透光平台、竖井壁、顶部出口 | 饥饿 → 吃饱 → 平台出现；由暗到亮；井底 → 顶部 | 进入顶部出口；需验证能否一束光直接跳过中段 |
| 4 · COME GO | 面内综合应用；引出黑镜 | 左侧导光穿栅栏 → 右侧拉滑轮 → 改道返回左侧喂兽 → 再去右侧 → 导光进入黑镜 | 普通镜、滑轮、顶部镜面、栅栏、野兽、黑镜 | 左右房间往返；野兽吃饱后离开；黑镜接光但当前视角看不到后续 | 进入黑镜并衔接下一关；首次跨面演出具体时点待定 |
| 5 · GO THROUGH | 理解 A/B 平行对应；改变返回位置绕墙 | A 导光入黑镜 → 抵达 B 光斑 → 推接收黑镜接光 → 保持返回镜原位会回到 A 墙左侧 → 移动 B 返回镜 → 抵达 A 墙右侧 → 推接收镜接光、穿栅栏 | A/B 接收平面、黑镜、普通镜、隔墙、栅栏、引导野兽 | A 左侧 → B；错误返回仍在左侧 → 调整后返回右侧；垂直光斑 → 可用平面光 | 穿过 A 右侧栅栏抵达出口；错误返回应可重试 |
| 6 · TRANSMISSION | 用斜向跨面光改变对应落点 | A 导光入黑镜 → 抵达 B → 将跨面光转成面内光 → 移动／调整返回黑镜 → 越过 A 隔墙 → 推门离开 | A/B 接收平面、黑镜、普通镜、隔墙、出口 | 垂直／斜向跨面 → 不同返回落点；B → A 目标区域 | 从 A 目标区域出口离开；与第 5 关的差别要落实到实际光路 |
| 7 · 1234（暂名） | 多隔间、多次跨面的综合解谜 | A 起点 → B 接光 → A 右上隔间 → 空中黑镜 → B 左下隔间 → 调镜上送并再次跨面 → A 右下接光 → 经上方镜从缝隙送给 A 左下野兽 | A/B 接收平面、多面黑镜、固定空中镜、普通镜、隔墙／缝隙、野兽；一个无效黑镜分支 | 光路逐段建立；同一 A/B 面的重复图是不同阶段，不是复制世界；无接收镜分支不能转为面内光 | 给最终野兽送光；是否直接作为游戏结局待定 |

第 7 关的图示步骤是预期解法，不能仅凭箭头断言几何可解。搭建时逐段记录“来源面／镜子编号／入射方向／落点／下一操作位置”，并实际检查遮挡、镜面尺寸与角色恢复空间。

## 3．道具与状态指导

| 道具／对象 | 可调整内容 | 状态 | 绑定方式／注意 |
|---|---|---|---|
| 普通镜 PlaneMirror | 位置、面内角度、是否允许推动 | 固定／可推；不同角度 | 继续用原 prefab；固定镜禁用推物和交互能力，不额外造同类套件 |
| 黑镜 DepthMirror | 位置、深度角度、所属面 | 发射／接收／错误角度；这些是光路状态，不是互斥道具类型 | 所属面选一个；不得靠 destinationView 强行传送；固定空中镜需单独布置支撑或固定刚体 |
| CrossFaceSurface | 平面位置、范围、所属面、允许实体抵达 | 无光／光斑／落点被占用 | 新功能 prefab；薄触发盒的本地 XY 面应与所属面平行；不是背景图，也不会自动生成于所有旧关卡 |
| 光源 | 方向、直径、玩法光强、长度、段数 | 开／关；弱／强 | 玩法光强默认 1，可设手电筒为 2 作原型；该数值是当前可调默认，不是已定美术规范 |
| 滑轮 | 行程、上升／下降速度、顶端锁定 | 低位／提升／下降／锁定 | 同一组件可选择限时或稳定型；不要求全部改为锁定 |
| 野兽 HungryBeast | 吃饱时间、目标标记、事件 | 饥饿／进食／吃饱 | 关系图可连接野兽 → 光源／机关／显现平台；对白、飞走动画不随喂食自动生成 |
| 显现平台 | 使用原 Platform 或 Glass，添加 RevealDevice | 隐藏且无碰撞／显现且恢复碰撞 | 菜单“选中平台／添加喂食显现功能”；在关系图连接野兽 → RevealDevice；默认隐藏 |
| 透镜 LensSurface | 固定偏折角、宽度倍率 | 直通／偏折 | 可添加于透光平台；0° 直通。未提供真实折射率、水面、焦点模拟 |
| LevelExit | 所属面、需要吃饱的野兽、下一 Scene | 未满足／可进入／已触发 | 新功能 prefab；默认仅实体进入，允许光团需显式开启；下一关为空则只完成本关 |
| 镜头／失败边界 | 跟随开关、偏移、速度、deathHeight | 跟随／观察／跨面转向 | 旧场景保持原配置；新建空关卡默认开启跟随、死亡高度 -100，按关卡实际范围修改 |

## 4．角色与光路状态

| 当前状态 | 进入条件 | 允许操作／后续 | 禁止与恢复 |
|---|---|---|---|
| 实体 | 出生、光团恢复 | 行走、跳跃、推动、E 交互 | 受实体障碍限制 |
| 受光充能 | 本面光照到实体 | 最强入射光决定方向；持续 2 秒化光 | 离开光或更换方向／来源重新计时；同帧不叠加充能 |
| 面内光团 | 化光，或黑镜将跨面光转回面内 | 随光方向行进；镜面反射；更强交叉光接管；空格退出 | 撞普通阻挡物在可容纳身体的位置恢复；同强度不争夺方向 |
| 跨面光团 | 深度镜将光射出当前平面 | 沿世界空间真实射线前进；接收黑镜可转回面内；接收平面可终止并恢复实体 | 普通镜／野兽不能截获；无接收面或镜时仍受距离保护，不凭空选目的地 |
| 抵达光斑 | 命中目标接收平面，且允许抵达 | 相机转到目标面，恢复实体，再推动黑镜接光 | 目标空间被占用时保持光团并反向；不传送到附近平台 |
| 通关 | 满足指定出口或兼容野兽目标条件 | 显示既有“关卡完成”；可配置下一 Scene | 不自动播放已暂停的 3D 回顾；不新增开发说明 UI |

| Q11 | 检查点、摔落恢复与机关重置范围 | 已有整关重开；图中未指定中途存档，不默认增加 |
| Q12 | A/B 面坐标与美术对应 | 必须按世界坐标对应；背面屏幕左右与正面相反，不能直接把两张图同向叠放当作世界位置 |

## 6．制作交接与范围

| 负责人 | 本阶段交付 | 验收 |
|---|---|---|
| 程序／引擎 | 补齐以上基础能力、面隔离、机关绑定与出口；保留既有 Scene 布局和引用 | 编译、针对性运行检查、逐关实际试玩 |
| Zoe | 按已验证原型搭建背景、地形与道具表现，统一角色、镜子、光斑和跨面演出风格 | 地形／道具与逻辑位置吻合；四面不混叠；玩法对象清晰 |
| 共同 | 确认待定项、解法、失败恢复、对白与终点；每完成一关即试玩 | 解法可完成、反馈可理解、无不可恢复卡关 |

现阶段交付的是可搭建能力与策划指导，不等于已经完成这七关。正式关卡布局、剧情播放系统、BGM、完整菜单及结局仍需后续制作；本次不擅自增加这些内容。
