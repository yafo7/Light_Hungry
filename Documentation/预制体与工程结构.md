# 预制体与工程结构

## 预制体清单

| 预制体 | 职责／需要配置的内容 |
| --- | --- |
| Player | Rigidbody2D、固定矩形碰撞、移动与能力、静态序列动画；速度、跳跃、解锁与放光时间可配置 |
| Sunlight | 窗框与固定方向光源；Direction 控制光向，Active 控制发光 |
| Flashlight | 可交互光源，E 开关；与阳光共用 LightEmitter |
| BeamSystem | 场景光路计算与绘制；每个场景放一个，需包含正确 Optical Mask |
| PlaneMirror | 两档平面镜；E 调角，Q 在三种尺寸间切换；角度、大小可配置 |
| ConvexLens / ConcaveLens | 更改光束宽度，倍率可配置；不是真实透镜光学 |
| HungryBeast | 嘴部圆形接收区和三态美术；Required Seconds 控制进食时间 |
| LightReceiver | 通用光接收器；可复用计时，后续再连接门等效果 |
| PushableBox | 推拉、遮光、垫脚、压按钮；不支持搬起或投掷 |
| PressurePlate | 玩家与箱子触发；两态视觉；不会被纯装饰物压下 |
| RailDevice | 刚体轨道台座；Travel、Speed、Left/Right Plate 可配置 |
| RailMirrorAssembly | 台座与镜子的嵌套预制体；提供可组合示例 |
| PulleyLever | E 切换轨道目标端点；必须关联目标 RailDevice |
| Platform / Wall | 地面与墙体；既用于碰撞也遮光 |
| Spikes | 接触玩家后重开房间 |
| ReflectUnlock / SwallowUnlock | 触碰后开放对应能力，并隐藏该拾取物 |
| LabSession | 场景配置、重置与能力初值；关联 Player、Goal、Beams |

测试房间内两个按钮关联到同一个轨道台座。手工使用这些独立预制体时，需要在 Inspector 连接实例引用，预制体资产不能持有特定场景对象的引用。

## 坐标与美术

游戏在 XY 平面，重力朝 -Y，正交相机沿 Z 轴看向场景。主角根节点位于脚底，碰撞体中心在根节点上方；动画只切图片，不改变碰撞体。

主角 PPU=256，Pivot=(0.5,0.0625)，512×512 图片内留白保留。镜头图片使用中心 Pivot，旋转与光学法线独立于画出来的高光纹理。野兽接收区也是独立的圆形触发器，避免用整只野兽的轮廓接光。

Sorting Order：背景 -20；普通美术 5；光束 25；世界文字 30。这里使用内置 2D Sprite 材质与 LineRenderer，没有安装 URP 或第三方插件。

## 碰撞层

| 层 | 编号 | 用途 |
| --- | --- | --- |
| World | 8 | 地形、轨道台座，阻挡光 |
| Player | 9 | 玩家角色 |
| Pushable | 10 | 箱子 |
| Optics | 11 | 镜子与透镜的光学触发面 |
| Receiver | 12 | 光接收区 |
| Triggers | 13 | 按钮、拾取、拉杆、危险区；不阻挡光 |

地面检测只检查 World 和 Pushable。光学面是 Trigger，允许角色穿过，但光路求交仍会命中；普通交互触发器不参与光学遮挡。

## 测试与构建

编辑器菜单 `Light Hungry/Build Windows prototype` 可重新打包。源码只依赖 Unity 2022.3 自带模块。

在构建版启动参数加入 `-labQA`，会启动无输入的集成验证，覆盖真实碰撞下的移动／跳跃、光线吸收、状态互斥、镜子交互、箱子、按钮、轨道、喂食和场景重置。结果写入工程 `Verification/playmode-results.txt`，并保存截图。

该验证是确定性场景联调，不能替代所有玩家站位、全部箱子堆叠与复杂轨道承载的人工试玩。开始做关卡前，仍应在 InteractionLab 中实际操作一次；复杂绳索与真实聚焦不在当前范围内。
