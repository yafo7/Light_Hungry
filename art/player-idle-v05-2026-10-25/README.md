# 小食光兽 · 完整角色逐帧待机 v05

日期：2026-10-25。制作模式：**complete sprite cels（完整角色逐帧图）**。每张 Sprite 都包含完整小食光兽，保留手部动作；预览与交付动画按帧清单直接播放这些完整图像。

## 动作方向

普通待机表现呼吸、眨眼和细微身体动作。思考待机保留抬手与收手，头先向画面左侧偏，稍作停留，再向右偏，快速眨眼两次，最后回正。眼睛保持黑色眼型，闭眼由画好的眼睑姿态表达。

本版使用完整角色逐帧绘画。播放时不使用骨骼、分层头部旋转、实时局部变形或整图 crossfade。

## 帧数与停留的含义

实际播放帧数、每帧时长和总时长以 animations.json 为准，预览页也直接读取同一份数据。

| 动作 | 播放序列帧数 | 时长 | 不同 PNG 图像数（本剪辑内去重） |
| --- | --- | --- | --- |
| 普通待机 | 36 | 3 秒 | 35 |
| 思考待机 | 72 | 6 秒 | 57 |

共导出 108 张帧文件。两组共享一个首尾姿态，因此全包按 PNG 的 SHA-256 跨剪辑去重为 91 张不同图像；不能把两列剪辑内去重数直接相加当作全包总数。

“播放帧位”不等于“互不重复的绘画张数”。为了让某个思考姿态停留，可以延长该帧时长，也可以复用同一完整帧；若采用复用，应在制作或检查记录中说明。未经逐图核验，不把帧位数量称为唯一绘画数量。

制作记录使用 frameOrigins 标明来源帧或复用关系。independentImageCount 与 uniqueFrameCount 在本包中均表示按最终完整角色 PNG 的 SHA-256 去重所得的“不同图像数量”，两个字段使用同一计数口径；它们不表示额外确认的独立手绘张数。播放帧数另行记录，重复停留不计作新增图像。

本版普通待机的末帧，以及思考的首尾帧，会复用普通待机首帧；左偏停留和双眨中也有完整姿态复用，用于衔接与安排节奏。具体位置以 frameOrigins 为准。

## 打开预览

双击 Previews/index.html。静止满 3 秒后进入思考；模拟操作会立即回到普通待机并重新计时。

支持暂停、单帧前后查看、0.25×／0.5× 慢放、动作阶段定位、深色／浅色／透明棋盘格背景，以及 128／256／384／512 像素显示尺寸。逐帧面板默认收起，每页显示 12 帧；点击“定位当前帧”可以找到正在播放的帧。

预览优先从图集直接取出一格完整 Sprite 绘制。所有图集完成加载和解码后才开始播放与计时。页面的刷新频率和动画实际换帧频率是两个概念：显示刷新可以是 60Hz，动画仍应按 frameDurationMs 规定的节拍更换完整姿态图，眨眼帧与停留帧不必等时。

Previews/idle.webp、think.webp、idle_3s_then_think.webp 分别为 3／6／9 秒，使用原始逐帧时长。comparison.webp 是 6 秒并排展示，按 20 毫秒取样完整 Sprite，没有插值或混合；精确关键帧节奏以交互预览、单独 WebP 和 manifest 为准。相同名称的 GIF 用于兼容预览。

## 文件与规格

- Sprites/Idle：普通待机独立透明 PNG。
- Sprites/Think：思考待机独立透明 PNG。
- Sheets：分页图集。
- animations.json：播放帧清单、每帧时长、动作阶段与图集分页。
- animations.js：同一份数据，供本地预览页加载。
- Source：完整角色逐帧生成图与相关来源资料。
- Previews：交互预览，以及提供时可用的 WebP／GIF 演示。
- QA：导出与浏览器检查结果。

单帧为 512×512 RGBA。保留完整透明画布与统一脚底锚点；参考脚底线沿用从顶部数 480 像素，Pivot=(0.5,0.0625)，PPU=256。

打包时以整张角色为单位做等比尺寸归一化和脚底对齐，统一角色显示大小；不拆开头、身体或手部进行旋转、拉伸或姿态拼接。每个播放位置仍使用一张完整角色图。

图集 firstFrame 从 0 开始，按每页从左到右、从上到下读取。每页只使用 atlasPages.frameCount 指定的有效格子；末页空白格不属于动作帧。

普通待机图集为 4096×2560（8 列×5 行，36 个有效格）；思考图集为 4096×4096 和 4096×512（8 列×8 行、8 列×1 行，共 72 个有效格）。

## Unity 导入与时长

沿用 Sprite (2D and UI)、Full Rect、PPU 256、Bilinear、Clamp、关闭 Mip Maps、首轮 Compression None，并开启 Alpha Is Transparency。

图集按 Grid By Cell Size 512×512 切片，Offset/Padding=0，Custom Pivot=(0.5,0.0625)。Max Size 不小于图集最长边。独立帧与图集选择一种导入即可。

**按 frameDurationMs 的累计时间放置关键帧**，保证停留和快速眨眼的实际节拍。不要把所有 Sprite 不加区分地套用默认低帧率，也不要把页面的刷新率当作动画姿态帧率。若使用 Unity 的 Sample Rate 网格，应选用能表达这些关键帧时间的精度，最终周期以 manifest 的总时长为准。

片段周期末放回首帧，让末帧的停留时间完整计入。物理碰撞体保持稳定，不随 Sprite 轮廓逐帧重建。

落地、无输入、无能力动作的静止状态持续 3 秒后进入思考；移动、跳跃、交互、能力、受伤或死亡应立即中断并重新计时。

## 检查与交付边界

浏览器检查按 manifest 的每帧时长，计算一个完整循环内应发生的换帧次数，再与实际绘制节拍对照；不硬性要求每秒出现 30 张不同姿态。检查同时覆盖图集完整性、触发、暂停、慢放、逐帧定位、缩略图分页与移动端布局。

本地 Chrome 的 19 项检查已全部通过：108 个播放位置完整载入，约 3.01 秒切入思考；约 6.21 秒采样中实际绘制更新 74 次，与清单规定的 74 次一致，实际换帧间隔相对目标时长的平均偏差约 6.85 毫秒。暂停、0.5× 慢放、阶段定位、分页及移动端布局正常，未发现脚本错误。深色、浅色、逐帧面板和移动端截图已检查；记录见 QA/preview-checks.json 与 QA/preview-*.png。

本版为完整逐帧美术与预览交付，尚未接入 Unity 工程。程序计时与动画切换需要在工程中使用同一份时长配置验证。

手绘风格的线条与色块仍有少许逐帧变化，末段收势接回普通姿态的局部轮廓也保留了轻微差异；请结合正常速度与慢放预览评审观感。
