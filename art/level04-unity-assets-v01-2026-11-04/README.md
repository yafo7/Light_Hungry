# 第四关 Unity 美术分层资源

由已选定的 v06 水彩效果图经内置 imagegen 编辑生成。没有改动 Unity 代码。

## 文件

- `clean-scene.png`：1858 × 846 静态场景底图，按原构图的 1859 × 846 虚拟画布配准。保留场景地形、跳台、根幕、根槽与固定支架，去掉人物、光线和可动道具。
- `props-atlas.png`：1024 × 1536 真透明图集，2 列 × 3 行，共 6 个道具。
- `runtime-atlas.json`：简化运行时图集信息，字段为 `width`、`height`、`props`。每项有 `name`、`rect`、`pivot`。
- `asset-manifest.json`：完整素材尺寸、主体边界、枢轴、参考位置与使用说明。
- `prompts.json`：两张图的完整生成提示词及工具来源。

## 图集顺序

1. 左上：导向叶槽（guide），含下端小铰链，可直接覆盖场景原转轴。
2. 右上：悬挂挡光叶帘（shutter）。
3. 左中：种荚（seed）。
4. 右中：镜面银片（mirror），中立姿态为竖直长片。
5. 左下：低矮压板（plate），右端铰链。
6. 右下：深灰目标鳞片（scale），无发光。

`rect` 使用图像左上原点，包含约 4 像素透明余量；`pivot` 是 Unity 兼容的左下原点归一化坐标。建议位置仅供配准，正式世界位置、旋转角与碰撞需由关卡搭建确定。

## 检查

已目视检查底图构图与跳台位置；已读取真实像素 Alpha，图集角落和各格间隔 Alpha 为 0，物件内部通常为 252 左右。某些预览器显示的黑色/棕色外部区域是 Alpha 为 0 的隐藏 RGB，不是需要再抠掉的背景。素材尚未经 Unity 运行时视觉验收。
