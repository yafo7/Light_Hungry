图中展示完成后的光路，各段按步骤接通，不是开局全部接好。绿色圆圈为可操作镜，灰色圆圈为固定镜；灰色虚位是道具旧位置。巨兽仅露浅白身体局部，暗灰菱形代表待照光鳞。

共同能力保持：站在有效光中三秒化光，玩家手动沿光线前后移动，松键停留。不加入强光自动捕获、任意飞行或光态跳跃。

## 各关的主要设计

### 04 蓄水浅池：分段接光

暗渠出水口 → 左岸转 M1 → 化光过第一段水 → 中岛恢复实体并转 M2 → 化光到右岸 → 转 M3 喂下腹光鳞 → 出口根缝松开 → 泵房管口。

中岛略高于两岸，入射与出射方向不同，M2 实际承担转向而非让光贴着镜面直穿。两段水面不得用普通跳跃跨过，装饰叶片不构成绕行踏点。M3 的最终喂光与出口联动是本版设计建议。

### 05 废弃泵房：光与实体对玻璃的不同通过方式

低处管口 → 井底接光 → 右侧中平台 → 左侧上平台 → 右上出口台 → 侧腹受光 → 检修孔与短梯 → 温室。

两块旧玻璃架允许实体站立，允许光线穿过。这样本关侧重竖向攀升与材质规则，第 06 关侧重升镜和往返。玻璃是对原图 UP UP 透光平台的场景化处理，属于本版新设计。

每面可调镜旁都保留固定落脚点。高处进光孔周围不设能直接到出口的踏台；需在灰盒中验证玩家不能从入射光逆行绕过整关。终点光鳞位于出口平台上方的后壁，最终光束不穿过实心平台。

### 06 温室苗床：往返有新目的

A 左下接光 → B 右下 → 操作 B 岸卷轴，升起 C 吊镜 → B 镜改向左上 → C 左上 → C 镜送光到 D → D 右上喂肋侧鳞 → 藤架入口。

三次跨沟抵达不同位置，保留上游已接通光路。C 镜升降，旁边实体踏台不动；卷轴与转镜是两个操作。出图只示意升起前后的镜位，不指定实际位移或滑轮倍率。C 镜旁需有可恢复实体并够到镜架的空间。

A 至 C 的高度、A 至 B 的沟宽都不能让玩家用普通跳跃绕开关键配光；B 镜的可转范围、C 镜下位遮挡需灰盒核对，防止不升镜也能直接接通终点。

### 07 叶幕走廊：跨到背面改变回程落点

A 前方遇墙 → 固定入口镜跨到 B 后方 → B 面落脚 → 实体将回程镜向右推过正面墙所对应的区域 → 再化光 → 返回 A 墙后固定接收镜 → 背侧光鳞受光 → 从藤架破玻璃口上雨槽。

A、B 是同一高度的前后两条通道，图中上下展开仅为阅读方便。跨层沿用光路移动，不新增自由 3D 行走。首次教学固定三个光学节点，仅开放 B 面回程镜的水平位移；水平入射光持续接入，B 面有连续安全地面。

旧镜位返回 A 墙前；正确镜位返回 A 墙后。对应立柱与虚线便于辨认坐标。移动镜未对齐、光斑落在墙上时，应在实体状态给出可见反馈，避免让玩家进入无处恢复的终点；具体容错方式待实现时确认。

## 空间连续性与验证边界

03 暗渠出水 → 04 浅池 → 05 池岸泵房内检修井 → 06 同一温室下层苗床 → 07 温室上层叶幕 → 08 破玻璃口外的雨槽。

本版有意简化背景，只确定走道、障碍、镜位、光路、身体局部和衔接点。不是水彩美术定稿或按真实尺寸制作的碰撞图。

安全落点恢复实体、玻璃材质、出口根缝反馈和跨层镜具体表现是本版设计建议，不覆盖用户已经确认的全局化光规则。几何反射、角色净空、最大跳距、充能位置、镜子交互距离与转场状态仍需 Unity 灰盒验证。
