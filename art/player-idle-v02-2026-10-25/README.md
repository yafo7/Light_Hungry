# 小食光兽 · 普通待机与思考待机 v02

日期：2026-10-25。以原美术包中的玩家为身份参考，用内置 image_gen 生成新动作。生成提示词在 prompts.json，原始生成图在 Source。本版是可审阅的逐帧美术素材，尚未导入 Unity 工程或验证游戏内状态切换。

## 本版动作

普通待机：轻微呼吸起伏、耳尖与尾巴的跟随、短暂眨眼，保持现有角色的亲近感。
思考待机：向上看、逐步抬手抵下巴、轻微歪头和回正、眨眼、放下手，回到普通待机姿态。
原型的嘴部偏开放；本版普通待机沿用这个表情，思考关键姿态改为闭口。嘴型本身不表示吞光能力激活。

两个动作均面朝右，向左可整体水平翻转；没有地面阴影、文字或烘焙光束。身体配色、梨形轮廓、短脚、卷尾和不对称耳角来自原角色。腹部沿用奶黄色色块，不承担新的储光状态逻辑。

帧序按左到右、上到下。网格和横条内容相同，导入一种即可。PNG 都保留完整的 512×512 画布；打包阶段只进行了裁片、每组统一等比缩放和脚底对齐，没有程序生成的角色替代帧或局部形变。

参考脚底线为从顶部数 480 像素；有效轮廓末行位于 y=479。Pivot 沿用 (0.5, 0.0625)，PPU 沿用 256。继承原角色脚部相对根节点的水平位置。

普通待机 07 与 00 共用同一张姿态；思考 00、11 与普通待机 00 共用同一姿态，减少循环接缝与动作切换跳变。共导出 20 张帧文件，不代表 20 张互不重复的绘画。

## 时长与触发约定

- 普通待机每帧毫秒：300, 200, 250, 70, 80, 70, 230, 300。
- 思考待机每帧毫秒：120, 120, 140, 180, 260, 140, 160, 260, 100, 140, 160, 220。
- 角色处于落地、无输入、无能力动作的普通静止状态时计时。
- 连续静止达到 3 秒后进入思考循环；预览中恰好对应两个普通待机循环。
- 移动、跳跃、交互、能力、受伤或死亡立即中断并重置计时，不等待思考播完。
- 储光或能力组合姿态需要另行制作，本包提供普通状态的待机动作。

3 秒是状态切换条件，不是塞在思考序列前的空白帧。预览已实现此条件；本次没有修改游戏程序。

## Unity 导入参数

沿用原项目素材约定：Sprite (2D and UI)，Full Rect，PPU 256，Bilinear，Clamp，关闭 Mip Maps，首轮 Compression None，Alpha Is Transparency 开启。

推荐使用网格图，按 Grid By Cell Size 512×512 切片，Offset/Padding=0，Custom Pivot=(0.5,0.0625)。网格 Max Size 至少 2048；如果导入 6144 像素的思考横条，Max Size 至少 8192，防止自动缩小。

非等时帧请按 animations.json 中的累计毫秒放置动画关键帧。在动画片段周期末再放一个首帧关键帧，保证最后一帧的停留时间也计入，最终周期分别为 1.5 秒和 2 秒；无需向 PNG 图集增加图片。不要对每帧使用紧贴外轮廓的自动切片或重建角色物理碰撞体。

## 验证边界

QA/export-checks.json 记录了逐像素 alpha 直方图、画布尺寸、脚底位置、边缘裁切、共享首尾帧和 GIF 元数据。透明通道、脚底对齐及序列结构通过检查。

本地浏览器预览检查也通过：3 秒前为普通待机，约 3.01 秒观察到进入思考；暂停稳定，模拟操作可重置，图片完整加载，移动端无页面横向溢出。记录见 QA/preview-checks.json，截图包括深色、浅色和移动端棋盘格。

AI 逐帧绘画仍可能有局部线条和色块的轻微跳动；请通过逐帧和 128px 预览判断是否接受这一版的动作幅度。尚未进行游戏内手感、状态切换或组合能力美术验证。
