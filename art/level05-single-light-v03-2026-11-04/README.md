2026-11-04。按用户最新反馈，替代 v02 的两束独立来光。全关只有一个窗缝光源、一条连续且不分叉的有效光路。保留泵房、玻璃、化光抵达的机关位与实体跳跃；本次为设计图修改，未改 Unity 工程。

## 改变的核心

M1 先把光送进 B 舱，取得跳台；玩家返回 A 后，把这束光收回，转送悬镜 M2。B 随即变暗，但打开的检修跳台锁止保留。光是玩家必须重新安排的行路资源，不能同时维持两条路径。

悬镜 M2 与控制台 C 分离：镜面悬在台下外侧，光能到，实体没有立足面；手轮在上方固定平台 C。玩家必须使用刚展开的实体跳台去镜背调镜，再返回 A，沿新路线化光前进。

## 四个光路状态与行动

| 状态 | 唯一有效光路 | 人物行动 | 此时无法做的事 |
|---|---|---|---|
| 1 访机关 | S → M0 → M1 → B | 井底化光到 A，实体调 M1 对准 B；化光入舱，恢复实体转 K1 展开跳台；沿原光返回 A | 不到 B 操作，检修跳台仍收起 |
| 2 改送悬镜 | S → M0 → M1 → M2 → 挡板 | 在 A 把 M1 从 B 改向 M2，B 熄灭；实体沿跳台爬到 C | M2 尚未对准 D，不能直接乘光到终点 |
| 3 接通高处 | S → M0 → M1 → M2 → M3 → 空墙 | 在 C 操作 K2 调 M2；观察 D 的光斑，接通后实体返回 A；重新化光经 M2 到 D | C 整个平台低于有效光路，不能原地化光；M2 本身也无实体落点 |
| 4 喂养救援 | S → M0 → M1 → M2 → M3 → 侧腹光鳞 | 在 D 恢复实体，通过 K3 调整 M3；同一束光喂鳞，根帘舒展后步行/短跳进入第六关温室 | 未调 M3 时光落空墙，不喂鳞 |

M0 是固定入口镜；M1 是在 A 反复调整的改道镜；M2 是由 C 的镜背手轮控制的悬置反射镜；M3 是 D 的末镜。K1 是 B 内检修卷轮，负责展开跳台；K2、K3 只是实体控制手轮，不另发光。

## 光与人的位置关系

- A 高处玻璃台、B 细缝舱、D 顶部玻璃夹层，首次到达都需要化光。
- C 通过实体检修跳台到达。M2 的镜面和 C 的手轮分离，不能直接沿光走到手轮旁。
- 只有透明玻璃让光和光核通过；实体可以站在玻璃上。B 的不透明壳体只留光核大小的检修缝。
- D 的玻璃底板、接顶左壁和上盖封闭，右侧出口由根帘遮挡；首次必须乘光穿入。巨兽只露浅白侧腹，未受光目标鳞灰暗。
- 图中的紫色虚线是机械联动关系，不是另一束光，也不是可行走路线。连杆和支架需位于光路后侧，不构成额外踏点。

## 防绕解与安全约束

1. **M1 只能调向左上扇区。**镜架限位覆盖 B 与 M2，不能直接转向右上方 D 或光鳞。需要显示实际镜架挡块，不能只用不可见规则限制。
2. M2 初态照向无落脚面的挡板；镜面自身和射线终点均不能恢复实体。玩家试走错误光路时可原路退回 A。
3. **M2 → D 必须避开 C 的全部可站充能范围。**主图 C 地面范围 x=1220..1380、y=665；M2=(1020,700)、D=(1390,425)。光线在 C 最左端高度约 y=551，已经高于台面约114图示单位；越向右越高。需结合真实角色高度与充光半径继续校准，不能把“不能在 C 化光”做成隐藏禁用区。
4. C 上方不放箱子、可站手轮、装饰横杆或额外跳台，防止站到光路里绕过回 A 的路线。全局规则仍是移动/跳跃不累计三秒充光。
5. B 的卷轮是锁止式，返回途中无需保持重量或赶时间。M1 改向必须在实体 A 操作；因此不会让仍在 B 的玩家失去返程光。
6. 调 M1 不改变 M0 → A 的入射段。C 调 M2 不改变 A 的安全来光。D 调 M3 不改变 M2 → D 的来光；调错后仍可沿光回退。
7. 来光窗缝旁没有可恢复实体的空间，防逆光爬到高窗跳关。镜架与控制轴不是可攀爬表面。
8. A、B、C、D 均有真实固定落脚面与身体净空；M2 只有悬挂镜头。非安全位置不恢复实体，不增加自由飞行或光态操作机关。
9. 死亡/跌落返回已抵达的安全位置，保留检修跳台的锁止状态；所有镜子可重复调整，不能把错误朝向做成永久失败。

## 难度来源

玩家需要理解三件事：光只能同时给一条路线；取得的机械通路可以在熄灯后留下；光到得了镜面，不代表角色能在那里恢复实体操作手轮。因此必须安排“先访舱开路 → 返回后收光 → 实体去镜背 → 再使用新光路”的顺序。

没有增加第二光源、分光、时间倒计时、光态开机关或自由飞行。三秒化光与手动前后移动保持原规则。
