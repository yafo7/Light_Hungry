# 食光兽 · 第一关三套美术方向

日期：2026-10-29。当前用于美术选型，用户选定方向后再搭建 Unity；本轮没有制作可玩关卡。

双击同目录的 `index.html` 即可离线查看。可切换 A / B / C 与完整场景、独立背景、前景道具，也可并排比较、点击放大。页面不依赖外部字体、脚本或网络；未完成的图片显示占位，文件就绪后自动重试加载。

| 方向 | 场景气质 | 唯一反射物 |
| --- | --- | --- |
| A · 苔墙拾镜 | 荒园苔绿、灰石、粗树根，植物逐渐覆盖旧墙 | 破碎银镜，保留一块可工作的平面 |
| B · 旧圃铜光 | 暖砖花圃、残缺拱墙，曾被照料的花园 | 旧植物标牌经过抛光的黄铜背面 |
| C · 藤影残灯 | 冷灰石柱、垂藤与薄雾，安静的庭院 | 旧园灯的平面镀银反光片 |

共同流线：左侧花园门进入 → 杂物中的反射物 → 石阶下仅露一小片尾尖光鳞 → 沿门槛裂缝抵达右侧倒扣陶盆的盆沿破口。

教学画面只表达一次反射：墙洞 → 反射面 → 光鳞。反射物绕竖直轴转动，安装倾角固定。光鳞从面向镜面的石阶侧隙接光，不能让光线穿过实体石阶。光鳞受光后轻微呼吸、发亮；生物仍埋在环境中，只显露局部。

构图目标：上部约三分之二由巨树与高墙占据。主角在当前示意图中约图高7%，用于看清形态；Unity搭建时可进一步缩小，以原草图的微小尺度为准。远景采用低对比的柔和水彩层次；前景地面、石阶、反射器、光鳞开口和出口陶盆采用较清晰的轮廓描边，帮助识别落脚处与交互对象。这些比例是画面观察与美术设计参考，不是运行时测量结果。

每套三张，共九张图纸：

- `A-scene.png`、`B-scene.png`、`C-scene.png`：完整场景示意，用于比较气氛、尺度、构图与光路。
- `A-background.png`、`B-background.png`、`C-background.png`：独立背景参考图。
- `A-foreground-design.png`、`B-foreground-design.png`、`C-foreground-design.png`：透明前景与道具设计板，上排为前景组合／组装示意，下排为三个道具放大图；包含部分墙体搭配元素。

这些是候选艺术示意，非 Unity 运行截图。独立背景可作为静态底图参考；背景、前景与完整场景不是像素严丝合缝、可直接叠合的自动分层。前景道具板是组合与单体设计参考，不是直接可用的纯地面切片；需要在选型后整理成独立模块，并确认尺寸、轴心、遮挡关系与碰撞体。透明度及各图的实际内容以交付 PNG 为准。
