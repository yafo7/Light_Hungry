# 第七关：叶幕走廊，两面场景示意图

依据 `art/level07-linked-faces-v02-2026-11-05` 的 v02 关卡设计绘制，沿用第六关温室的淡水彩、纸纹与植物插画风格。

## 最终图件

- `07-front-leaf-corridor.png`：正面，叶幕走廊。入口镜 P、旧落点 R0、三片展开踏阶、K前、贯通上下的厚叶墙、墙后 R1 与食光兽背侧局部。
- `07-back-trellis-maintenance.png`：背面，藤架检修侧。接收镜 Q、实体跳台与 K背、轨桥、卷起的挡叶、空置 R0 停靠位与 R1 上的单辆镜车。

两张图采用相同世界横向展开方向，以便比较两面的镜窗与结构关系；不是把真实摄像机旋转 180 度后的直接截图。两面基础走道处于同一高度。

## 展示状态

统一画机关已开启后的布局：正面踏阶展开，背面轨桥落下，背面挡叶卷起，镜车位于 R1。正面永久厚叶墙仍然阻挡通路。

唯一光路为：日光 → 正面 P → 背面 Q → 背面 R1 镜车 → 正面 R1 固定镜 → 背侧光鳞。前图的两段可见光束属于同一条穿过背面的光路；正面 R0 熄灭。高处跳台用于实体跳跃。

背面 K背 的连接件通向正面踏阶；背面轨桥和卷帘通过另一处穿架轴连接 K前。正面最左端旧门上的轮形把手属于第六关衔接入口装饰，不增加新的解谜机关。
