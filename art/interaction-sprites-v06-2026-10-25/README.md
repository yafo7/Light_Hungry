# 小食光兽 · 收势修正与道具交互 v06

打开 **Previews/index.html** 查看四组动画。页面支持道具交互按钮、正反方向、暂停、逐帧滑块、慢放、游戏尺寸和透明棋盘格。角色卡提供“定位5.83s”“定位5.91s”，底部可展开v05/v06末段动态对比。

## 本次修改

思考待机保留原有抬手、微偏头、抵下巴、双眨眼和收手。原5.91秒硬切回idle的末段已替换为11张选用的完整角色过渡图，并在5.80秒进入稳定休止姿态；5.83秒与5.91秒现在使用同一完整图像。仍保持6秒周期，78个播放位置。尾段最大相邻前景RGB平均差由原末端34.74降低至23.83，最后接回idle的一步降至15.16；这些数值仅用于定位差异，不能替代视觉评审。

三组道具按原图风格制作：Wheel正反整圈转动；Lever左右换档；Mirror左右调角。正反动作复用完整帧，切换时不变换局部零件。镜子按图中独立金框镜头和立柱底座组装，未使用石块底座版本。

帧位含停留复用。反向clip引用同一批PNG，不是额外生成的独立画。主Sprites目录共161个文件；Source里的原画、候选、V05输入仅用于来源追溯与重建，不能当作新增动画帧导入。

- **Sprites/**：完整透明512×512 PNG。
- **Sheets/**：已规整的512格图集，最长边不超过4096。每页有效格数见manifest。
- **animations.json / animations.js**：顺序、逐帧时长、循环标记、轴心、来源。
- **Previews/**：交互页面与GIF/WebP。Lever/Mirror动图额外加入端点停留方便观看，不是游戏clip时长。
- **Source/**：AI原画、裁出整帧、旧版输入和原始道具参考。
- **QA/**：导出与浏览器检查、末段新旧对照、全帧透明/裁切记录。
- **prompts.json**：内置image_gen.imagegen工具的完整提示词集。
- **Tools/**：Node + sharp打包脚本，Playwright预览检查脚本。

## 导入与接入

沿用512×512、PPU256、Sprite(2D and UI)、Full Rect、Bilinear、Clamp、关闭Mip Maps的素材规格。首轮关闭纹理压缩，开启Alpha Is Transparency。图集按512×512零间距切片，读取atlasPages的有效格数量。

角色、Lever与Mirror的Pivot为(0.5,0.0625)，底部参考线Y=480。Wheel的Pivot为(0.5,0.5)，轮轴参考位于画布中心。交付图已经包含完整道具；运行时直接切Sprite即可。不要再同时旋转整个Wheel图片或Mirror底座，否则会叠加第二次运动。

按frameDurationMs累计时间排关键帧。角色think使用非等时帧；不要用统一12fps替换时间表。Lever/Mirror为非循环clip，结束后保持最后一帧，反向动作从该完整姿态开始。碰撞体、绳索、光学法线和逻辑状态由工程独立控制，不逐帧跟随绘画轮廓重建。

## 检查与边界

12项导出检查、16项浏览器检查通过；逐帧透明通道、512画布、边缘不裁切、动画时长、两端一致性、3秒触发、指定时间对照、切换、暂停与慢放均已检查。压缩包附文件校验值。

本版是完整逐帧Sprite美术素材，未接入Unity工程。绘画仍有少量色块与轮廓变化；并不声称每帧几何和笔触像素完全相同。预览可在128px与慢放下继续审图。旧v05目录保留。

如需重建，先运行Tools/prepare-bridge.cjs、Tools/prepare-props.cjs，再运行Tools/export-all.cjs；依赖Node与sharp。Tools/check-preview.cjs需要Playwright和本机Chrome。
