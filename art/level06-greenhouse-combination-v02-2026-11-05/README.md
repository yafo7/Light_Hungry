# 第六关 v02：温室苗床——途中落脚，往返换位

2026-11-05。替代 v01 的 A→B→C→D 逐站转镜方案。此轮只重构设计与图件，没有修改 Unity 工程，也没有生成关卡最终美术。

## 提案的核心

保留第 05 关泵房检修口 → 两座温室苗床之间的沟槽 → 第 07 关叶幕走廊的空间衔接。仍是一束棚缝日光，不分光、不生成临时第二光源。食光兽露出浅白肋侧，只有需照射的目标鳞初始灰暗。

新增一只挂在苗床间的育苗托盘 P：

- **低位是维修落脚点**，玩家在光路中途恢复实体、短落到盘上，够到沟壁低处的帘绳扣 K。
- **高位是光路接力点**，托盘边缘的固定镜片才与 C 的出射光对齐，将光转交给 D。

两种用途不能同时存在。必须先用低位完成维修，再沿原光返回 B，把托盘升回高位，最后返回 A 收走下层光、改通上层。开过的遮光帘保留状态，光线本身则不能同时保留两条路线。

## 机关与场景结合

| 位置 | 物件 | 功能与造型 |
|---|---|---|
| S | 温室破损玻璃后的棚缝光 | 唯一光源；高处无可站落脚面，不能沿逆光跳关 |
| A | 苗床边的改道镜 | 回收温室镜片，装在有两段可见限位槽的园艺支架中；选择下层 B 或上层 C |
| B / H | 缠着藤绳的园艺卷轴 | 固定岸边的升降控制；将 P 置于低位检修挡或高位接光挡，松手后机械锁止 |
| P | 悬吊育苗托盘 | 旧陶片浅盘、藤绳吊索、边缘固定镜片；高低两处都是真实可站平台 |
| K | 沟壁低处的帘绳扣 | 固定在沟壁检修口，不随 P 移动；实体必须在低位 P 上站稳才够得到 |
| G | 不透光的旧育苗遮光帘 | 横过 A→C；拉 K 后卷起，靠棘爪锁开，离开或升降 P 均不复位 |
| F | 大片不透光育苗标签 / 遮光隔板 | 接顶隔板仅留窄孔；玩家在 C 观察光斑转镜，使光穿孔而非照板面 |
| 回光阶 | 固定在沟壁的两级小搁板 | 与 P 分离，给维修后的实体提供逐级回到 A→B 光束里的站位 |
| 右挡光片 | P 后方接顶的旧苗床挡片 | 孔位与 F 不同，只放行 P 正确反射的光；吸收 P 不在高位时穿孔直行的光，避免错误光意外到达 B 或 D |
| C / D | 校准镜 / 末镜 | C 负责窄孔与 P 对准；D 在实体抵达后，把末段从空墙转向暗鳞 |

图是机关关系示意，正式美术可把卷轴与扣件做成旧园艺器具或藤结机构，不需添加微型现代机械。

## 正常通关路线

| 步骤 | 有效光路与状态 | 玩家动作 | 获得的条件 |
|---|---|---|---|
| 1 | S→A→B；G 关、P 高 | A 化光去 B；在 B 恢复实体，操作 H 降 P | 沟中央出现可以够到 K 的落脚点 |
| 2 | 仍为 S→A→B；P 低 | 从 B 沿光回退，在 P 左侧上方按 E，短落在盘上 | 把光路中的某个位置用作实体入口，而非一直走到终点 |
| 3 | 下层光保持；G 锁开 | 实体操作 K；走两级回光阶，站光三秒，再化光向右回 B | 开放 A→C，同时保留返程 |
| 4 | 下层光保持；P 升高 | 在 B 操作 H，把 P 升回高位；沿光回 A | P 从维修落点改为上层接光镜 |
| 5 | A 改上层，下层熄灭 | 化光到 C；实体转 C 镜穿过 F 窄缝；重新化光经 P 到 D | S→A→C→P→D 连通 |
| 6 | 保持所有入射段 | 在 D 恢复实体，转末镜照亮暗鳞 | 出口根帘舒展，实体进入叶幕走廊 |

其中：

- **第一次回程 B→P**：为了在路途中恢复实体，完成低处维修。
- **P→B**：为了将刚用过的维修落点改成高位光路节点。
- **第二次回程 B→A**：为了回收下层光，再改变下一段目的地。

到 C 后不能只按一次按钮自动完成校准：应允许玩家按镜架范围连续调整或使用足够清楚的角度档，观察光斑是否对准 F 小孔。图中阶段 5 展示校准后的状态；C 初始角度照在隔板上。D 初始出射照空墙，喂鳞后才开放出口。

## 可推理的错误状态

1. **先把 A 调上层，但 G 还没开**：光止于 G，角色可以沿原路退回 A；看到帘绳与低处 K 的连接。
2. **开了 G，却没把 P 升回去**：能到 C，也能让光穿过 F，但高位没有镜片接光。光打在 P 后的挡片上。玩家可以 C→A 回退，把 A 再改下层，去 B 修正 P 高度。
3. **C 镜角度错误**：光斑落在 F 板面，实体仍站 C，输入光没有变化，可以继续调镜。
4. **D 镜角度错误**：人物已在 D 安全台，来光不变；可以反调，也可以沿光回退。

不能把“错误状态”做成无限开放的额外光路。特别是 P 低位时，C 穿孔直射的光须被挡片截停，不能延伸到 B 的身体充光区域。否则存在绕路后升 P 截走自己返程光的软锁。

## 途中恢复实体：规则与当前程序的区别

全局已有规则继续保留：站在有效光中约三秒化光；光态由玩家控制沿光前后移动；实体才能操作机关；光态不能自由飞行。

本关拟明确补充的反馈是：**光路中途按 E，脚下短距内有可站平台且身体与下落通道净空时，在当前位置恢复实体，再受重力短落到平台；没有安全落点则保持光态。**

以角色身高 h 为基准，先用约 2h 的落点搜索范围作为灰盒起点；实际数值需测试。不是允许任意高空退出并飞到暗处。这样既可以实现用户提出的半途落台，也保留全局的可恢复性。

当前 Unity `LightFormAbility.TryRestoreNear` 是向下射线找到安全地面后，直接将角色放在地面；它没有表现“光中变回实体，再下落”的过程。因此此处是**设计扩展，尚未实装**。下一轮程序需要检查身体出现位置、完整下落路径、落面法线，并恢复正常重力，不应把“落到 P”硬编码成关卡传送。

P 下落区与回光区分开：玩家先落在 K 左近的低盘面；维修后走到右侧固定小搁板，让身体进入原光，再静止三秒。上层 P 本身同样可以落脚、重新充光，不用隐形规则禁止玩家停留。

## 空间与防绕解约束

- A 两个镜向扇区用实际可见的镜架限位表达。G 只挡 A→C，不影响 A→B。操作 K 不会截断原返程光。
- C 平台使用透明玻璃：上行光可以从下方穿入，实体可以站在其上。入射光在操作 C 时持续保留。
- F 接顶，窄缝只容光核通过；C→D 直连、C→低位 P 都会被隔板遮挡。只有高位 P 的方向通过孔后能形成有效反射。
- P 低位的镜片连同矮支架须完全低于 A→B 光束；藤绳在玩法平面之后，不截光、不提供落脚碰撞。
- P 升降途中若盘面暂时遮住下层光，玩家此时在 B 实体操作，必须待盘面抵达并锁止后才可再次化光出发；不应在飞行期间远程升降。
- K 固定在沟壁，无可站碰撞面；操作要求实体站稳。回光阶距 K 必须大于实体交互半径；即使玩家先落到回光阶，也不能绕过降 P 的准备步骤。
- 设实测最大跳距为 R：A 与低 P、最右回光阶与 B、上层 P 与 D 的净空应留出大于 R 的余量（建议先以至少 1.4R 校核）。不要仅凭示意图看似宽阔判断不可跳过。
- 角色在上层 P 恢复是合法动作。上层 P 有重新充光站位，与 D 距离不可直接跳过；镜架、藤绳、遮光挡板上缘不应成为隐藏捷径。
- P 后方右挡片同样接顶，仅在 P→D 正确反射方向上开窄孔；C→F 直行的错误光落在右挡片孔下的实体板面。不能使用有外露平顶的小柱来截光，否则其顶面会变成额外恢复点。错误终点旁没有短距可恢复平台。
- 死亡重生使用最近已抵达的、与当前光路兼容的固定 A/B/C/D 安全台；P 不作固定存档落点。K 的锁止及 P 档位保留。上层失足优先回 A/C，不把玩家送到已熄灯的 B。
- 禁止以暗中关闭实体恢复、突然改变三秒充能规则或自动替玩家转镜的方式弥补布局漏洞。

## 提示与节奏

初入先展示同一托盘上有镜片、下方沟壁有够不到的帘绳扣，给出“同一物件的两种用途”的线索。B 降盘时短暂跟随镜头到低处 K，展示可落脚而不是直接提示答案。

玩家沿下层光经过 P 上方时，首次出现轻提示“E：恢复实体”，并显示可落点轮廓；允许停住观察后再按，不做限时窗口。P 上的台阶把视线引回仍亮着的原光。

开 G 时短暂展示帘子卷起，露出 C。若玩家忘升 P 到 C，则展示光穿孔后打在挡片上的光斑、以及空置的高位接收位置。提示可分三级：看见光斑 → 观察缺失的镜片位置 → 回想卷轴的另一档。不直接把所有步骤写在游戏画面上。
