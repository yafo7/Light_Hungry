# 第七关叶幕走廊：分层美术与可复用构件

本目录保存第七关前后两面的干净背景、透明构件图集和 Unity 构件包。已接入的场景为 `UnityProject-NOVA-URP/Assets/Scenes/SeventhTrellis.unity`。两面共用同一束光、同一辆镜车；本目录的图片不承担碰撞或机关状态。

## 原图与来源

素材通过内置 **imagegen** 制作。背景来自已确认的两面水彩示意图，清除了角色、光束、可移动机关及前景平台，避免独立对象移动后留下原图残影。提示词按文件保存，没有对原始概念图作覆盖。

| 文件 | 内容 | 尺寸与格式 | 提示词 |
|---|---|---|---|
| `background-front.png` | 正面温室后景，无玩法碰撞 | 1774 × 887，RGB | `front-prompt.txt` |
| `background-back.png` | 背面藤架检修侧后景，无玩法碰撞 | 1774 × 887，RGB | `back-prompt.txt` |
| `trellis-atlas.png` | 叶片踏台、轨桥、镜窗、镜车底架、密叶板、卷帘辊 | 1536 × 1024，透明 RGBA | `atlas-prompt.txt` |
| `atlas-inspection.json` | 图集透明边界的测量记录 | JSON | — |

| `asset-package-audit.json` | 文件校验值、预制体与依赖检查记录 | JSON | — |

当前交付采用**完整后景 + 透明图集 + 独立 Unity 预制体**。六个新物件没有各自另存成单独 PNG，而是用网格 UV 选取图集中的区域。它们在 Unity 中仍可独立摆放、缩放、隐藏和复用。

## Unity 中如何分层

正面根对象 `FACE_A_Front_LeafCorridor` 与背面根对象 `FACE_B_Back_Maintenance` 都包含：

| 子组 | 用途 |
|---|---|
| `01_Background_NoCollision` | 减淡柔化的背景贴图；不提供任何平台碰撞 |
| `02_HorizontalPlatforms_Collisions` | 两岸、跳台、叶墙、轨桥及实际水平碰撞面 |
| `03_ReusableProps_Mechanisms` | 镜窗、镜车、手柄、传动绳、滑轮、光束、目标鳞与出口 |

主角、跨面光路和摄像机控制器位于这两个根对象之外。切换视角时只启用当前一面的场景对象，保留全关的机关与镜车状态。

平台顶面的碰撞线与图集中真正的承重边缘对齐，不拿花叶最高点或轨桥后方的装饰细杆当成可站面。密叶板按原始比例分段重叠铺设，避免把单片叶子拉伸成整个关卡的高度。

## 新的 6 个可复用预制体

位置：`UnityProject-NOVA-URP/Assets/Prefabs/TrellisReusable`。

| 预制体 | 内容与用途 |
|---|---|
| `LeafShelf.prefab` | 带支架的叶片育苗踏台，正面展开跳台和背面固定跳台共用 |
| `RailBridge.prefab` | 带轨面的木桥模块，用于背面展开的轨桥 |
| `MirrorWindow.prefab` | 铜框穿架镜窗，作为光路在两面间的对应接口 |
| `MirrorCart.prefab` | 镜车底架与已有独立反光镜组合，镜片与车架分离 |
| `LeafPanel.prefab` | 可拼接密叶板；关卡中的长叶墙由 builder 使用同一图集区域铺成 |
| `RollShade.prefab` | 卷起叶帘的辊轴及安装件 |

`LeafPanel` 是独立提供的复用模块；当前场景为控制长墙尺寸和末段裁切，直接生成叶板网格，没有该预制体的源实例。其余 5 类新预制体均在当前场景中存在源实例。

已有 `GardenReusable` 中的岸壁、独立反光镜、手柄、滑轮和根须拱架继续复用。素材包同时带上该文件夹原有的 9 个构件，便于后续关卡继续组合；这不表示第七关使用了它们的每一种。

这些预制体主要提供美术、材质、网格与 `GardenReusableProp` 元数据。碰撞体和机关逻辑由场景搭建器与运行脚本配置，**不是导入任意工程后就会自动完成跨面解谜的整套机关**。素材包不包含第七关场景、两张后景和完整关卡控制器；这些内容已经保存在当前 Unity 工程，原图另在本目录中。
