## 这一版的核心变化

原版是进入背面、平地推镜、返回墙后。现在加入两次实体平台跳跃，各自取得**另一面的通路**：

1. **背面爬升找 K背**，展开正面断裂的叶片踏阶。
2. **返回正面，沿新踏阶找 K前**，放下背面镜车轨桥并卷起挡叶。
3. **再回背面，推同一只镜车过桥**，将回到正面的位置从叶墙之前改为叶墙之后。

角色跨面顺序为 **A → B → A → B → A**，共四次跨面。难度来自前后结构的对应、机关依赖和路线判断；不用倒计时，也不要求在镜头转换时做精确跳跃输入。

## 机关及其场景造型

| 对象 | 所在面 / 位置 | 功能 | 状态留存 |
|---|---|---|---|
| 固定入口镜 P 与接收镜 Q | 正面入口 / 背面对应 x | 同一束来光经过藤架纵深镜窗进入背面 | 固定，不由玩家改角 |
| K背 | 背面上层花架检修台 | 经同轴藤绳展开正面三片育苗搁板 | 棘爪锁住，不要求持续站人 |
| 正面踏阶 | 叶墙之前的断裂走道 | 展开后形成到 K前的实体跳跃链 | K背开后保留 |
| K前 | 正面踏阶末端、高处叶墙前 | 一根连杆同时放下背面轨桥、卷起断轨处的挡叶 | 机械锁止，不改变光源或镜向 |
| 背面轨桥及挡叶 | 背面镜车 R0 与 R1 之间 | 关闭时实际断轨与挡叶阻断镜车；打开后成为连续平直轨道 | K前开后保留 |
| R 镜车 | 背面，R0→R1 | 只有一只可推动镜车；沿水平来光移动，选择回到正面的对应镜窗 | 可推回、无消耗、无倒计时 |
| R0 对应镜窗与终止罩 | 正面墙前安全台 | 接回光核并提供实体落脚点；在台边就把出射光截停 | 不向跳台区供光 |
| R1 对应镜窗及固定镜 | 正面墙后安全台 | 接回光核，将同一束光送向背侧暗鳞 | 对位时持续照鳞 |

所有机关可使用旧育苗架、藤绳、叶柄、陶木托片和少量园艺铜件呈现。K背与K前的连动轴穿过同一藤架，在两面留相同刻痕或种子形图案，帮助玩家理解“另一面发生了什么”。不要做成没有机械联系的远程魔法按钮。

## 通关行动与光路

### 1. 正面观察阻挡，再借光进背面

灯芯精灵从第六关到正面入口安全台。前方厚叶幕/花架墙贯穿到温室上方结构，无法翻越；断开的正面踏阶尚未展开，K前高处可以看见但到不了。

玩家站到 P 的来光里三秒化光，沿光经过纵深镜窗到背面 Q，在宽阔台面恢复实体。镜头完成翻面过渡后再交还平台跳跃操作，不让玩家在看不见落脚点时掉落。

此时光路是：**S → P（正面）→ Q（背面）→ R停在R0（背面）→ R0接收镜（正面）→ 本地终止罩**。这是一条连续光路，不是前后各有一束独立光。

### 2. 背面跳跃，上行打开正面踏阶

R 镜车此时停在 R0。玩家先沿背面三片固定花架搁板向上跳，抵达 K背所在检修台，实体站稳操作。镜头短暂预览正面踏阶展开，配合相同轴心符号，随后回到角色所在的背面。

背面跳台与横向光束分离：光束在地面附近，终止于 R0；不穿过任何高处跳台，无法化光直接去 K背。支架位于玩法平面之后，不遮断来光，也不给额外碰撞捷径。

K背只展开踏阶，不移动 R，也不改变光路。玩家沿实体平台回落到背面安全地面，重新站光化光，经 R0 返回正面。

### 3. 正面跳跃，到 K前打开背面轨桥

R0 正面的接收镜旁有小型不透光终止罩，接收的光在安全台边就被吸收。它不会沿前方踏阶延伸，玩家不能用光态绕过这段跳跃。

玩家恢复实体，沿已展开的三片踏阶向右上跳，抵达 K前。K前同时放下背面的水平轨桥并卷起挡叶。预览必须让玩家看清：这是镜车可经过的实际轨面，不是新的光源。

踏阶初始收在苗床背板后侧，不留可站横边；展开后才转入角色玩法平面，形成水平承重台面。实体跳跃有合理落脚宽度与余量，不要求踩帧或连续零失误。

### 4. 原路返回，再去背面推镜车

玩家沿正面踏阶向左下返回 R0 安全台。K前操作没有改变 R0 的来光，因此可以在同一光束中充能三秒，沿纵深路径逆向回到背面 R0 镜车旁。

背面桥未打开时，轨道有真实缺口，并有实际挡叶拦住由高平台跳向远岸的路线。挡叶与轨桥由同一机关联动，不添加第三把钥匙。K前打开后，镜车才有连续支撑可从 R0 推向 R1。

玩家实体抓住车柄、沿水平轨道向右推。镜车移动期间，Q 到镜车的水平入射光一直接入；推车动作不计入三秒静止充能。松开车柄并站稳在光里后，才可再次化光。

### 5. 对位 R1，回正面墙后完成救援

R0 和 R1 是**同一镜车的两个停靠位置**，不是两辆车。两处轨道上有对应镜窗的清晰刻痕和可感知停靠槽。玩家把车推到叶墙右侧对应的世界 x，即 R1，再化光沿新的纵深回路到正面墙后。

此时光路为：**S → P（正面）→ Q（背面）→ R停在R1（背面）→ R1固定镜（正面）→ 背侧暗鳞**。正面 R0 的光熄灭。光鳞受光后亮起、出口叶幕舒展；角色在墙后安全台恢复实体，向右进入第八关雨槽屋脊。

## 让组合谜题可读、可修正

- **第一层判断：为何先在背面爬高？**镜车眼前的桥没开，正面踏阶的铰轴与背面 K背 的连杆相连。玩家先取得正面路线。
- **第二层判断：为何又回正面？**K前 在刚展开的踏阶末端，控制的是背面轨桥；两面必须互相借路。
- **第三层判断：镜车应该停在哪里？**同一根立柱和叶墙轮廓提供 x 对应参照。R0 回到墙前，R1 才回到墙后。
- 推到中间位置时，纵深出射光会照在实心衬板上；只有 R0/R1 两处实际镜窗能跨向正面。不是任意位置按键传送，也不能从半途落到正面高处机关旁。
- 停错时玩家仍在背面安全轨道上，可以继续推或回推。K前、K背的开路状态保留；不必重做平台跳跃或重开关卡。
- 角色在正面操作 K前 时没有任何物件远程移动 R，不会突然收走正面回程光。

## 跳跃、几何与防绕解约束

1. 所有平台顶面和轨道都水平，镜头垂直当前面的玩法平面。背景纵深可以有透视，可站边缘不能随其歪斜。
2. 以实测最大稳定跳距 R 与跳高 H 为约束：相邻必要跳台采用明显小于极限的距离与高度；落脚台宽度建议不少于约两个角色碰撞宽。让难度来自折返与识别去向，不来自刚好擦边才能跳到。
3. K前 距正面入口安全台超过一次可达范围。收起的踏阶、装饰叶尖、镜架与连杆不提供旁路碰撞。
4. 正面厚叶墙一直连接上部框架，不留能够从 K前 平台翻过去的墙顶。
5. 背面 K背 高台与远岸之间有联动挡叶；在桥未开时，不能从高台做大跨度下落跳绕到远岸。
6. 背面镜车必须沿真实连续轨道移动；断桥边的挡块阻止镜车被推进坑里。轨桥展开锁定后才解除挡块，不能因为人物能跳过就允许镜车悬空滑行。
7. 背面低处来光在各跳台下方通过，角色在走道上的身体净空和镜车的最大外包络都须通过。支架退到背景层，不能无解释穿过实体挡住光或车。
8. R0 的终止罩必须在正面踏阶之前，输出方向不可调整到跳跃区。它同时保留镜旁足够的三秒充能站位。
9. 镜车只有到实际镜窗才跨面通光；中间位置的出射被实心衬板截停，不创造任意跨层入口。图上紫线代表纵深路径，实际需实现三维折转或等价的层间光路，不是竖向射线。
10. 全关一只活动镜车，其余镜固定。两个机关只改变平台/挡叶，不另开光源、不分光。

## 相机、重生与提示

- 初次跨面镜头过渡使用同一根藤架立柱作位置参照。可短暂显示另一面的投影位置，但轮廓预览不是第二个角色，也不能直接在另一面操作。
- 机关触发后短暂预览另一面的变化，再回到实体角色所在位置；预览期间不处理跳跃输入，避免角色在镜头外失足。
- K前/K背不使用持续压板。玩家离开或化光后，已展开的路径不复位，不用携带重量，也不重复第六关的高低托盘用途。
- 跳跃失误返回该面已抵达的固定安全台，保留机关状态。镜车若在移动途中，需要将重生点选在当前可达的背面固定走道；不能把玩家送到光已经熄灭且无法回去的正面 R0。
- 如果复位镜车，应同时选用与复位位置匹配的角色安全台与光路状态，不能单独复位其中一个对象。
- 第一次接近背面断轨可让镜车轻撞挡块并发出反馈；第一次 K背 操作显示正面踏阶展开；第一次推到 R1 时用镜窗边缘高光与轻微卡位确认对应关系。
