# 小食光兽 · 连贯待机 v04

日期：2026-10-25。本版使用同一套角色原画图层制作连续动作，再按时间采样烘焙成透明 Sprite 帧。头部通过刚性旋转进行约 ±5° 的轻微偏头，不对头部做非等比缩放、拉伸或局部形变。

## 动作与节奏

- 普通待机：舒缓呼吸和眨眼，30 fps、90 帧、3 秒。
- 思考待机：头向画面左侧轻偏，停留，再缓慢转向右侧，快速眨眼两次，最后回正；30 fps、180 帧、6 秒。
- 偏头的进入、转向和收势使用缓入缓出；头部轮廓、五官相对位置来自同一套图层。
- 双眨眼只更新眼睑的遮挡范围；眼睑随头部整体变换，保持黑色眼型，不使用翻白眼。
- 小手自然下垂，不再加入抬手抵下巴的动作。

实际帧数、时长与动作阶段以 animations.json 为准。所有帧为 512×512 透明 PNG；待机满 3 秒后的触发条件保留。

思考节奏为：0–0.25 秒自然微动，0.25–1.05 秒左偏，1.05–1.65 秒左停与轻回弹，1.65–2.95 秒连续转右，2.95–3.25 秒右停，3.25–约 3.687 秒快速双眨，随后轻回弹并在 4.10–5.20 秒缓慢回正，5.20–6.00 秒接回自然微动。

## 先看预览

双击 Previews/index.html。默认播放普通待机，静止满 3 秒自动进入思考。可以暂停、0.25×／0.5× 慢放、单帧前后查看、点击动作阶段定位、切换深色／浅色／透明棋盘格背景，或查看游戏尺寸下的表现。

判断连贯性时，优先看交互预览的 30 fps Canvas 播放，或 Previews/think.webp、Previews/comparison.webp 动图。WebP 采用 33／34 毫秒帧时长；GIF 仅作兼容预览，时间精度较低。

逐帧面板默认收起；展开后每页显示 12 帧。翻页只查看该页，播放时不自动频繁翻页；点击“定位当前帧”可找到正在播放的帧。模拟操作会立即回到普通待机并重新计时。

预览从 animations.js 加载相同的帧清单和时长，优先直接从 atlasPages 图集取格绘制。图集预载完成后才启动计时；播放时不重新构建整套缩略图。帧图和图集内容相同，预览不会额外插入实时形变。

## 文件与透明规格

- Sprites/Idle：普通待机独立帧。
- Sprites/Think：思考待机独立帧。
- Sheets：分页图集，按每页左到右、上到下读取。
- animations.json：帧时长、动作阶段和图集分页。
- animations.js：供本地预览使用的同一份数据。
- Previews：动画预览与 GIF 等演示文件。
- QA：导出与预览检查记录。

图集页的 firstFrame 从 0 开始；columns、rows 指定每页网格，单格为 512×512。请保留完整画布与统一脚底锚点，不要逐帧按外轮廓自动裁紧。

普通待机共 2 页图集，分别为 8×8 和 8×4 格；思考共 3 页，分别为 8×8、8×8 和 8×7 格。每页 PNG 宽 4096 像素，末页部分格子为空白。

脚底参考线沿用从顶部数 480 像素，Pivot=(0.5,0.0625)，PPU=256。透明 PNG 是正式素材；带展示背景的 GIF 用于查看节奏。

## Unity 导入

沿用 Sprite (2D and UI)、Full Rect、PPU 256、Bilinear、Clamp、关闭 Mip Maps、首轮 Compression None，并开启 Alpha Is Transparency。

图集按 Grid By Cell Size 512×512 切片，Offset/Padding=0，Custom Pivot=(0.5,0.0625)。Max Size 不小于选用图集的最长边。独立帧与图集选择一种导入即可。

每页只按 atlasPages.frameCount 取有效格子，末页空白格不要加入 AnimationClip。Unity 的动画 Sample Rate 明确设为 30，避免默认低帧率再次造成卡顿；按 animations.json 中的 frameDurationMs 设置关键帧时间。片段周期末放回首帧，让最后一帧的停留时间完整计入。保持物理碰撞体稳定，不随 Sprite 轮廓逐帧变化。

角色在落地、无输入、无能力动作的静止状态下累计 3 秒后进入思考；移动、跳跃、交互、能力、受伤或死亡应立即中断并重置计时。

## 验证边界

本版交付透明美术与本地预览，尚未接入 Unity 工程。预览的 3 秒触发、慢放和中断功能不代表游戏程序已修改。

QA 中的浏览器检查会记录实际帧覆盖、图集加载方式、触发时刻、暂停与逐帧、缩略图分页，以及一次本地播放采样。浏览器采样仅说明本次本地预览结果，不代替 Unity 内的显示与性能验证。

本次本地 Chrome 检查中，270 帧均由图集覆盖加载，静止约 3.005 秒进入思考；完整思考循环的约 6.2 秒采样接近 30 fps，播放期间没有重建缩略图。暂停、0.5× 慢放、分页与逐帧、动作阶段定位、移动端布局均已检查。详情与截图见 QA/preview-checks.json 及 QA/preview-*.png。
