## 三个新增控制位置

| 位置 | 为什么需要化光 | 恢复实体后的操作 | 对路线的影响 |
|---|---|---|---|
| A 高处玻璃台 | 高差与横距超过普通跳跃，第一束光从玻璃底下穿过 | 拉 K1，抬起上游早已能看见的遮光片 G1 | 打开 A 到 B 的光路 |
| B 窄缝检修舱 | 壳体完整封闭，只有光核能穿过的细缝 | 转动 K2 检修卷轮，松开卡扣并展开外侧三块检修跳台 | 建立 A 到 C 的实体攀升路线；玩家需先沿原光返回 A |
| D 顶部玻璃夹层 | C 到 D 的高度不可直接跳上，光从玻璃底板穿入 | 转 K3 手轮，远控落脚点之后的末镜 M3 | 将上段日光转向侧腹暗鳞；持续照射使出口根帘舒展 |

K2 是泵房旧检修结构的卷轮，通过连杆/拉索展开锁止式踏板，不是控制水流的阀门。本次不增加可升降镜架，避免与第六关的升镜主机制重复。

## 完整解法

1. 从第四关进入井底，站在 S1 的有效光中三秒，沿 M0 → M1 到 A。穿玻璃后，在安全台面恢复实体。
2. 拉 K1 抬起 G1。先观察新光段照进左上检修缝，再化光从 A 到 B。
3. 在 B 内落脚恢复实体，操作 K2，远处三块跳台展开并锁止。
4. 重新化光，手动沿同一束光回退到 A。返回不是重复跑图，而是抵达刚刚开启的实体路线起点。
5. 恢复实体，沿三块错层跳台向右、左、右折返上升，最后跳到 C。
6. C 有独立窗孔 S2 的来光。调整 M2，将其引向 D；化光穿过 D 的玻璃底板，在顶部夹层恢复实体。
7. 转 K3 调 M3，使目标鳞受光。出口根帘舒展，实体短跳到检修孔，经短梯进入第六关温室苗床。

## 规则与机关状态

- 全局化光规则保持：有效光中站定三秒；手动沿光路前后移动；松键停留。光态不能操作机关，也不自由飞行。
- 延续第五关 v01 的材质提案：玻璃支撑实体，但让有效光束和沿光行走的光核穿过。此材质规则尚未在第五关 Unity 场景验证。
- K1 和 K2 都是锁止机关，离开后保持开启，没有限时返回或持续压板要求。
- S1 与 S2 物理分离，不相交。S1 在 B 截止；S2 在 C 接收。C 的初始镜角只把光投到近处空白壁面，无法抵达 D。到 C 调镜后，上段路线才成立。
- M3 初始角度把出光送往空白墙面。图中显示正确喂光角度；K3 调的仅是 M3 出射方向，不影响 C → D 的入射段，所以随时可以沿来光退回 C。
- 源光处没有净空足够的实体落点，不能逆着入射光去高窗后恢复并跳过关卡。
- 巨兽仅露浅白侧腹，目标鳞灰暗；受光反馈是鳞片亮起与局部呼吸，巨兽不会移动或随行。

## 防绕解与防软锁要求

1. A 的玻璃台最初不可从井底跳上；未展开的检修踏板不保留可站立侧边、支架或装饰碰撞。
2. B 壳体包含顶、底、侧壁，检修缝小于实体净空；舱内仍有完整身体落脚、移动和转轮的空间，不能直接从 B 掉到 C 或梯道。
3. 三块检修跳台展开后，实体才可从 A 达到 C。D 具有接顶的封闭左侧玻璃壁、上部泵壳顶板和根帘封住的右侧出口，首次只能沿光穿玻璃底板进入。C 到 D 的高度超过最大跳高，其他跳台不能借落差跳到 D。
4. 光线穿玻璃时，不得让不透明支架挡在正中。绳索/连杆在图面后侧，紫色控制线不代表光学遮挡。
5. A、B、C、D 均有固定安全落点；机关把手在实体能走到的位置。狭缝中禁止恢复实体。
6. K1 只关闭其下游，初次未开时仍可返回井底；K2 不切断返回 A 的来光；M2/M3 调角均不切断玩家当前安全平台的入射光。
7. 回退和跌落可返回最近安全落点，保留已经完成的锁止机关；不得因掉入井底或误调镜产生不可恢复状态。
