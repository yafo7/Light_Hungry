## 1. 地下生长的光源

将人造检修灯改成虚构植物“地光球茎”：根系从土层穿过砖缝，球茎垂在拱顶下，厚苞叶包裹带荧光的肉质内芯。玩家触碰低处根须结，苞叶缓慢张开，露出朝下的集光口，形成用于谜题的光束。根须不再画成电线。

这是架空植物的光学特性，不声称现实中的荧光球茎能自然发出同样的定向强光。局部暖光用于强调球茎，旧图中的地面小灯也已删除，避免额外有效光源干扰全局化光能力。

## 2. 配重必须是过闸的必要踏点

A 段两岸之间计划保留约 3.6H 净距，远超当前控制器同高度约 1.96H 的理想跳距。中位配重将它分成约 1.2H 和 1.15H 两段，踏板宽约 1.25H。

删掉两岸之间、配重下面的全部跳台和可踩碎石。水槽下不设可以横穿至对岸的行走面；掉落触发回到左岸的本段恢复点，保留开光与可继续调整的机关状态。两岸之外的热身跳台不受影响。

镜托高位时配重降下，必须在已到对岸上层后再升镜。上层的稳定落脚台和第二个操作柄仍可使用，不把玩家困在不可逆状态。

## 3. 反光片与透光孔是两个不同功能

用户圈出的原图 B 段中央砖柱处，原意是透光孔，但画得像一个亮面装置。现改成无金属边框、无发光描边、暗色内腔的矩形孔，并直接标注“透光孔：不改变光向”。

真正的反光片只有升降架上的那一片：把球茎向下的光转成向右的光；镜托升降又改变出射光的高度。中位可以过闸，高位对准砖孔并把光送至 C 段的尾根光鳞。中央孔不反射、不折射，也不产生新的光。

## 4. B 段流线与新平台排布

上一版文字提到了折返，但美术中的平台没有形成可靠、明确的这条路线。本版重新布置了落脚点，不只是往旧图上加箭头。

1. 从上层绞盘台向右，经下降落脚台来到低层长廊。青色 **①** 沿长廊向右行走。
2. 在低层右端，先跳上一个未编号的小托台，再跳到右侧 **②**。增加小托台是为拆开原先过高的一跳。
3. 从 **②** 向左上方跳到 **③**，再向左上方跳到 **④**，形成珊瑚色折返段。
4. 从 **④** 转向右上，跳到 **⑤**，再向右经过 **⑥** 进入上层廊道，接往 C 段。紫色表示这一段。

平台 ③④⑤⑥ 使用后壁悬臂托架，支撑不延伸成挡住下层走道的前景实心柱。没有从低层直接升到出口的附加楼梯，也删去了原来右下方容易误读成另一条路线的多余台面。

图中青色、珊瑚色、紫色均为玩家路线，金色才是光路。跳跃箭头只是方向与落脚点示意，不是物理抛物线或保证可达的实测轨迹。

## 灰盒时必须保留的关系

- 荧光球茎是真实场景光源；三秒化光能力仍全局保留。
- 配重下不能留实体绕行路；不能只删美术而保留碰撞。
- 下层长廊至 ③④ 的高度不可一跳直接达到；② 到 ⑤ 也不可直跳跳过折返。
- 悬臂平台既要有稳定落点，也要给下面的起跳留头部净空；角色固定跳高参数不变时需逐跳检查。
- B 段最终平台仍低于主光束；早段站立位置不应直接进入高光路跳过整段平台挑战。
- 插画允许背景纵深，但全部玩家路线必须在同一可玩侧视平面解释，不能靠不明确的前后景台面补齐跳跃。

完整通关、落点余量与防绕行仍需 Unity 灰盒验证。本版确认的是美术修正与清晰的路线意图。
