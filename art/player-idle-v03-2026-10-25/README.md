# 小食光兽 · 普通待机与思考待机 v03

日期：2026-10-25。使用内置 image_gen 继续迭代现有小食光兽的逐帧美术，保留原角色造型与配色。相较 v02，本版将普通待机增加至 16 帧、3 秒，思考待机增加至 32 帧、6 秒；重点调整思考时的左偏、停留、右偏与快速双眨眼。共导出 48 张 512×512 透明帧。

## 先看动画

双击 Previews/index.html。普通待机满 3 秒后进入思考循环；点击“模拟操作 · 重新计时”可重新演示触发。支持暂停、上一帧／下一帧、点选单帧或动作阶段、0.5× 慢放、深浅背景与透明棋盘格，以及 128／256／384／512 像素显示尺寸。

预览页通过 animations.js 加载与 animations.json 相同的帧路径与时长，在本地 file:// 环境可直接打开，无需服务器。请保留 Previews、Sprites、Sheets、animations.js 的相对位置。

- Previews/idle.gif：普通待机，16 帧、3 秒循环。
- Previews/think.gif：思考待机，32 帧、6 秒循环。
- Previews/idle_3s_then_think.gif：静止 3 秒后思考的整体节奏演示。

## 本版动作

普通待机：更舒缓的呼吸、眨眼与耳尖／尾巴跟随，保持双脚落地。

思考待机：头先向画面左侧偏，稍作停留，再向画面右侧偏，随后快速眨眼两次，最后回到普通待机。左右均以屏幕方向描述。眼睛保持角色原有黑色眼型，闭眼以眼睑动作表达；不使用向上翻的白眼。

思考的左偏停留为 0.8 秒；右偏后的两次快速眨眼集中在 0.56 秒内。前后都留有缓慢过渡与收势，使快速眨眼与偏头动作形成节奏变化。

| 思考阶段 | 片段内时间 |
| --- | --- |
| 进入思考 | 0.00–0.38 秒 |
| 头向左偏 | 0.38–1.46 秒 |
| 左偏停留 | 1.46–2.26 秒 |
| 缓慢转向右侧 | 2.26–3.88 秒 |
| 右偏停留 | 3.88–4.18 秒 |
| 快速眨眼两次 | 4.18–4.74 秒 |
| 放下手并回正 | 4.74–6.00 秒 |

身体仍面朝右，短脚、卷尾、奶黄色腹部、不对称耳角与粗轮廓来自原角色。此处的腹部颜色不代表新的储光状态。储光及能力组合状态需要另行配套美术。

## 素材位置与规格

- Sprites/Idle：普通待机的独立透明 PNG 帧。
- Sprites/Think：思考待机的独立透明 PNG 帧。
- Sheets：按网格打包的序列图；帧序从左到右、从上到下。
- animations.json：帧路径、每帧时长、循环、触发及动作阶段。
- animations.js：同一份数据供本地预览页加载。
- Source：生成原图。
- prompts.json：本轮生成提示词。

| 动作 | 独立帧 | 网格序列 | 循环时长 |
| --- | --- | --- | --- |
| 普通待机 | 16 张 | 4 列×4 行，2048×2048 | 3 秒 |
| 思考待机 | 32 张 | 8 列×4 行，4096×2048 | 6 秒 |

若采用横条版，请按 animations.json 的 horizontalPages 分页导入与排序。每页 4096×512，含 8 帧；普通待机 2 页、思考待机 4 页。本版不使用将 32 帧全部拼成一张的超长横条。

单帧画布为 512×512 RGBA。参考脚底线沿用从顶部数 480 像素，Pivot=(0.5,0.0625)，PPU=256。请保留完整透明画布与统一锚点，避免逐帧紧贴外轮廓裁切造成抖动。

## 触发与播放约定

角色处于落地、无输入、无能力动作的静止状态时开始计时。连续静止满 3 秒进入思考循环；移动、跳跃、交互、能力、受伤或死亡应立即中断并重置计时。

3 秒是状态切换阈值，不是思考动作中的空白帧。动作阶段停留与两次快速眨眼使用不同帧时长，请以 animations.json 的 frameDurationMs 为准，不要简单把所有帧按等时长播放。

## Unity 导入

沿用原项目约定：Sprite (2D and UI)、Full Rect、PPU 256、Bilinear、Clamp、关闭 Mip Maps、首轮 Compression None、开启 Alpha Is Transparency。

网格图按 Grid By Cell Size 512×512 切片，Offset/Padding=0，Custom Pivot=(0.5,0.0625)。Max Size 不小于所用图集的最长边；独立帧与图集选择一种导入即可。

动画关键帧按每帧时长累计放置，在片段周期末放回首帧以包含末帧的停留时间。保持物理碰撞体稳定，不随 Sprite 轮廓逐帧重建。
