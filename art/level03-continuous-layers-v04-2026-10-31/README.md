## 前景与世界坐标

镜头周围的粗根须属于**屏幕空间前景**：固定铺在单个 16:9 镜头上，世界移动时它不移动，不参与碰撞。它没有被拼成整条长图，也没有重复绘制在 A、B、C 的边界。Unity 中可放到 Screen Space Canvas，或作为正交摄像机的子物体覆盖视口。

背景砖墙、拱顶上自然垂下的细根属于**世界空间后景**，会随镜头移动。两种根须在文件和查看页中分开。

跳台、水和道具均使用同一幅 2170 × 725 世界坐标，左上角为 `(0,0)`、Y 向下。图集的 `unityRect` 和 CSV 已转换为 Unity 左下角原点。`pivot` 在 JSON 中以左上角归一化，CSV 的 pivotY 已反转。

背景源图有上、下白色导出边缘，源 PNG 保留未改；清单和 SVG 采用 `x=0, y=10, width=2170, height=702` 的 UV 窗口显示，再映射到世界画布。导入时按清单设置，不要把白边作为场景内容。

## 中景与交互物

水层独立于跳台，以便做 UV 流动和水面扰动。预览先绘制完整水层，再叠跳台与道具；最后重复使用同一水图的 `y>=542` 部分覆盖入水边缘。两个水实例引用同一个 PNG，不是两张内容不同的图。

道具切片为：荧光球茎、唤醒根结、升降反光片、配重踏板、绞盘、固定导架、移动踏板、水轮转子、食光兽光鳞。其中固定导架只是机关支撑，水轮是传动件，光鳞是受光目标，独立拆分不等于都要求玩家直接操作。

两只绞盘复用同一素材；A、B 共用**一个球茎和一个反光片**。中央墙柱中的矩形开口是透光孔，不再增加反光镜。配重下方保留水面，导架底部横档在世界实例中用 UV 窗口省略，避免看起来像另一块可落脚的平台。

光束、长绳、导轨作为独立线条几何组合；未来可换成 Unity LineRenderer、网格或材质。光不会烘焙在背景中。预览中中位/高位反光片与配重反向移动；这些只是艺术位置，不是物理模拟。

## 对位与验证边界

这些素材使用内置 **image_gen**，根据用户的三段图先重构连续母图，再分别生成各层；不是对原图做无损逐像素切割。局部纹理、轮廓与层间尺寸存在差异，本包通过画布坐标和 UV 窗口对位。全部生成提示词见 [generation-prompts.json](generation-prompts.json)。原始绘制 PNG 的字节未被重新编码。

已检查透明通道、所有素材加载、图层开关、A/B/C 切换时根须位置固定，以及两档机关的反向位移；记录在 `QA/`。`连续长图_叠层.png` 是实际组合预览的浏览器截图，母图与实际组合均保留，便于比较。

这是分层美术交付，**尚未导入或替换 Unity 第三关**。本版不增加人物贴图，不修改已导入的 3D 主角。v03 的约 76H 长度、跳跃参数与知识锁目标仍是设计方向；当前像素坐标不能直接当作最终碰撞坐标，跳台间距和通关路径仍需灰盒验证。
