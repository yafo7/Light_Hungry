## 规则与读图

蓝线为实体行走/跳跃；金线为有效光束；橙色虚箭头为玩家化光后的行动顺序；紫线或配对字母表示纵深跨层。光态仍由玩家手动前后控制，箭头不强制单向。部分橙线略偏离金线是为了读图，实际光态贴合光路。

图示是完成态，按步骤逐段建立。安全落点恢复实体、配重锁止、根缝响应、具体跨层镜表现均为本版设计建议，不是对已有全局规则的静默修改。调镜位旁应留遮阴操作区与相邻充能位，避免自动三秒化光干扰操作。

后半程不是逐关机械加码：08—10强化既有能力并交替平台与观察，11引入角度/纵深关系，12组合旧机关，13短暂舒缓，14综合达到难度高点，15用熟悉的操作收束剧情。

## 各关设计

### 08 雨槽屋脊｜背脊表皮

平移镜位会改变折转后的光柱位置；角度固定也能解谜。

1. 沿雨槽短跳到镜轨
2. 把滑镜推至窄口下方
3. 化光穿口并越过断槽
4. 到右岸转末镜，照亮背脊鳞
5. 根缝松开，从阁楼窗进入09

检查要点：滑镜仅沿轨道水平移动，来光水平且持续覆盖轨道。；窄口只供光通过；断槽不能普通跳过。；固定上镜只是反射节点，不要求在空中操作。；滑轨末端留止挡，目标光鳞完成后才开放窗边根缝。

### 09 园丁阁楼｜肩部局部

物件可遮住机关的观察方向；换观察面发现拉绳，实体路线不变。

1. 接住天窗来光，发现布片挡光
2. 沿种子袋和木架攀升
3. 切固定观察面，发现手套背后的拉绳
4. 收起挡光布并固定在开启位
5. 到末镜调光，照亮肩鳞后从通风口出发

检查要点：切观察面不是跨层传送，角色始终处在同一实体通道。；旧布位置画虚线，最终光路不穿过仍关闭的布。；旧放大镜只是透光框，没有本关新聚焦规则。；巨大手套仅为遮挡视线的前景，不能误做挡住必经路线的碰撞体。

### 10 常春藤坡｜肩颈局部

两段导光之间需要恢复实体跳跃；不能一束光飞完整关。

1. 沿固定藤根短跳到第一片叶台
2. 调叶片露珠支架，接通窄根缝
3. 化光穿缝，在中间干燥根台落脚
4. 实体连续上跳，到第二片叶台
5. 调第二组露珠，把光送入藤结镜和肩颈鳞
6. 沿末段光路登上塔楼破窗

检查要点：露珠画为折射，不用镜子图标；两处调节均在固定叶台完成。；根缝只让光粒通过；短跳间距另做灰盒验证。；两道独立天空来光分别照两组露珠，没有未说明的凭空光源。；中间落点用吸光陶片终止首段光路，安全恢复后才跳跃；恢复行为仍为设计建议。

### 11 观测暗室｜颈侧局部

斜向跨层改变落点；错位孔必须在真实纵深里共线

塔楼破窗进入 A → 侧面观察两道错孔 → 调入口镜纵深角度 → 化光到 B → 转接收镜接固定回程 → 返回 A 墙后喂鳞 → 塔内楼梯上第12关。

检查要点：A/B 主图同高展开，不是上下楼层；俯视图显示真实深度。镜子旁有实体站立位和邻近充能位；不能由投影重合替代实际通光。

### 12 露天观星台｜角根旁局部

光源沿竖向轨道持续照到升降镜；改变镜高使出射光越过固定遮挡。配重可锁止，不限时。

1. 从 11 关塔内楼梯登上观星台
2. 在左侧安全地面操作配重卷轴，将观测镜从低档升到高档
3. 锁止配重；高位光越过挡板，经固定末镜照亮角根旁光鳞
4. 穿过挡板下方通道，沿矮台到外侧检修梯，下到 13 关

检查要点：高低两档都需持续截获入射光；低位光明确被瓦檐挡住。锁止状态不自行回落。出口开启以鳞片受光为条件，不能直接走过而跳过目标。

剧情反馈：站上花园高处，只看见巨大的角根表面；不展示完整角或全兽。

### 13 面颊花廊｜眼睑旁局部

只重用遮光与转镜，降低认知负荷，让巨兽局部回应成为重点。

1. 沿 12 关外梯到花廊
2. 转动叶柄拉杆，翻开遮住光路的花瓣
3. 在安全地面微调小镜，把光送到眼睑旁的鳞片
4. 观察眼睑轻动，沿旧灌溉槽下行进入 14 关

检查要点：光照目标是眼旁鳞片，不是眼球。花瓣和小镜都可在实体地面操作；不设置限时收拢。

剧情反馈：一小段眼睑轻轻起伏，回应玩家；避免完整眼睛、脸部或突然开眼惊吓。

### 14 暖房根室｜胸侧局部

四房间与两条后廊接力；复用跨层和穿隙，不增加新规则

A1 左上 → B上廊 → A2 右上稳定点Ⅰ → 经空井斜向跨层到 B下廊 → A3 左下稳定点Ⅱ → 光穿根隙到 A4 右下 → 喂胸侧鳞 → 同高塌墙到第15关。

检查要点：A面隔间与B面上下廊均有实体分隔，不能直接步行绕过。γ光路经过前后走道之间的开放空井，不能穿楼板；稳定点保留上游光路。配对字母为跨层连接，不是自由传送门。

### 15 中央心庭｜胸前光鳞

独立光路逐一接通并保留；三束光汇向同一胸鳞，综合旧规则，不添加新能力。

1. 从 14 关塌墙进入同标高心庭
2. 对准左环镜 A，接通第一条独立光路
3. 登矮台对准中环镜 B，保留第一路
4. 对准右环镜 C，三路持续照向胸前光鳞
5. 步入中央暖区，观看胸前光脉与新芽回应

检查要点：A/B/C 各有独立入光孔，不让一面普通镜凭空分光；三路可交换完成顺序，操作地面始终可达。终局不引入未经确定的主角牺牲或消失。

剧情反馈：胸前光脉汇合，新芽长出。镜头始终停留在局部庭院与身体表面。
