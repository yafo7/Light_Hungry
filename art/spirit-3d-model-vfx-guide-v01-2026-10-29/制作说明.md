# 光精灵：3D 模型、正交画面与流光特效制作说明

2026-10-29。以最新“大头、缩小 20% 身体、水滴手足”的形象为依据。以下按 Unity URP + Blender 建模提出方案，不代表已确定你的引擎版本。

本包提供两张建模参考插画和实施说明。图片由内置 imagegen 生成，尚不是同一个真实 3D 网格的正交渲染；建模时需统一正、侧、背的厚度与轮廓。本轮没有制作 FBX、绑定文件或可运行 Unity 特效。

## 两张三视图怎么使用

- 01-model-orthographic.png：基础实体模型，正面、右侧、背面。用来建立体积、头身比与短小手足。
- 02-vfx-orthographic.png：在同样体型上增加光焰与拖尾的美术示意。透明火舌和脱落碎光属于特效层，不作为主体雕刻。
- 第一张故意采用完整圆头。实体头部承担面孔和稳定轮廓，上后脑的透明流焰再把它变成概念图里的精灵。第二张表现分层关系，最终火焰色温与粒子密度仍按原稿调节。
- 侧视图朝右，所以后脑、背部与流光的默认后方在画面左侧；正面/背面视角需要对应同一个空间方向。

## 1. 3D 场景怎样看起来像 2D 插画

建议使用 URP 的 Universal Renderer / 3D 渲染路线，场景、角色、门洞和平台都保留真实 3D 厚度，将 Camera 的 Projection 设为 Orthographic。正交投影消除近大远小，纸感、颜色、轮廓与明暗仍由美术和材质控制，不会自动生成水彩风格。[Unity 相机说明](https://docs.unity3d.com/cn/current/Manual/urp/camera-component-reference.html)

关卡可以限制玩家沿指定通路或当前平面移动。观察视角切换时，切换相机朝向或观察位；角色、镜子、光源仍在同一套世界坐标内。平台碰撞和镜面射线判定使用 3D。为了看见室内而暂时隐藏某片墙的渲染，不等于取消它的碰撞和遮光。镜面射线可用 Physics.Raycast 和 Vector3.Reflect 计算。[Raycast](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Physics.Raycast.html) / [Reflect](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Vector3.Reflect.html)

先在真正的游戏相机尺寸中检查角色：能看清脸、四肢和胸口光核，比近景里有多少粒子更重要。应同时检查正面、侧面、背面和切换过程，避免某张透明片换到侧面就完全消失。

## 2. 应该建什么样的模型

下列尺寸与面数只是建议起点，需要按最终相机尺度和设备验证。

| 部分 | 建模内容 | 与特效的关系 |
|---|---|---|
| 头部 | 封闭、圆润的完整体积；前脸略平；保持大头和很小的身体 | 细碎火舌、飞散星尘不雕进主体 |
| 躯干和手足 | 小梨形身体、短四肢、水滴状手足；肩、肘、髋、膝留变形环线 | 不需要真实手指、脚趾或复杂手部骨骼 |
| 眼睛/嘴 | 贴图或独立小贴面，能随头部保持正确位置 | 面部不发射火焰；不要被全头高亮冲掉 |
| 胸口光核 | 独立小网格或材质遮罩，位置贴近胸面 | 单独控制亮度、颜色和呼吸节奏 |
| 光焰薄片 | 另做约 3–5 张有轻微弯曲和纵向分段的薄面，根部贴住后上脑 | 它们是透明材质的承载几何，不是实体尖刺 |
| 发射区域 | 后上脑一片简化发射面；上背部一个挂点 | 用于限制粒子出生位置，避开面部 |

建议以脚底为原点，Y 向上，角色正面为 +Z；Blender/FBX 导出时统一轴向。将无特效的总高记为 H，可先以头部约 0.62–0.66H、颈下约 0.34–0.38H 建立体型。先做 4,000–8,000 三角面的主体作为预估预算，保留充分的圆滑轮廓；这不是实测性能结论。

骨架可先采用 17 根左右：Root、Hips、Spine、Neck、Head，加左右各 UpperArm / ForeArm / Hand、Thigh / Shin / Foot。若动画需求简单可以减少，若需要独立光焰摆动再增加少量辅助骨。

主体展开 UV；把面部、胸口光核、后上脑发射区分开。准备发射遮罩或专用发射网格，保证光尘不会从眼睛里钻出来。光焰薄片的 UV 纵向统一从根部到尖端，便于材质控制流动与渐隐。

模型美术交付建议包括：.blend 源文件、带骨骼 FBX、基础色贴图、发光遮罩、发射区域遮罩、独立光焰薄片，以及站立/走动/跳跃/交互动作。这里只说明后续交付内容，本包没有这些模型文件。

## 3. 头部光焰与运动拖尾分别做

| 层 | 建议实现 | 行为 |
|---|---|---|
| 稳定身体 | 可蒙皮主体 + 水彩色块材质 | 保留可读轮廓、五官与动作 |
| 贴头的光焰 | Head 下的弯曲薄片 + 流动/溶解材质；或局部空间短寿命粒子 | 根部跟随头，不在走路时整片脱离 |
| 脱落星尘 | 从后上脑发射的 World 空间粒子 | 出生后留在世界中，逐渐漂移、变小和消失 |
| 背部尾迹 | 上背部 World 粒子；需要连续光带时再叠加一条窄 TrailRenderer | 随移动产生，停下后自然消散 |

Local、World 与 Custom 决定粒子相对哪个坐标空间模拟。[Unity 模拟空间](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/ParticleSystem.MainModule-simulationSpace.html)

头部先做少量宽而柔软的光焰片，材质中让噪声/流动纹理从根部走向末端，边缘逐渐溶解，再补少量碎光。大片水彩色块负责造型，小粒子负责呼吸感。避免用数百个小白点代替整个发型。

背部拖尾可先试 0.3–0.7 秒粒子寿命，按角色移动距离发射；高速时增加发射量或长度，停止时停止新增运动尾迹。Rate over Distance 表示按移动距离发射，Rate over Time 表示按时间发射。[Unity Emission](https://docs.unity3d.com/6000.0/Documentation/Manual/PartSysEmissionModule.html)

尾迹方向可以混合“少量向上漂移”和“实际运动速度的反方向”。不要把左右方向写死为世界 X；角色转弯和关卡观察方向都可能改变。已出生的世界空间粒子继续消散，新粒子改用新方向，不要把整条旧轨迹翻到角色另一侧。

若使用拉伸 Billboard，可先将 Camera Scale 设为 0，防止镜头转动本身拉长粒子。正交镜头下可用 View 对齐面向相机平面的粒子；这是渲染朝向，和 Local/World 模拟空间是两件事。[Unity Renderer](https://docs.unity3d.com/6000.0/Documentation/Manual/PartSysRendererModule.html)

传送或瞬移时清空旧轨迹与需要重置的世界粒子，避免横跨关卡的长线；正常相机切换不必默认清空。[TrailRenderer.Clear](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/TrailRenderer.Clear.html) / [ParticleSystem.Clear](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/ParticleSystem.Clear.html)

## 4. 怎样保持水彩，而不是霓虹球

主体第一版采用稳定的不透明表面，通过白蓝色叠色、柔和明暗和局部边缘效果表现轻盈感。纸纹与色块优先贴在模型 UV 上，避免角色走动时纹理像投影一样滑动。眼睛区域保持清晰，胸口和少量光焰尖端才是最亮的位置。

粒子贴图需要自己制作：不规则白金色火舌、半透明水彩碎片、柔散星尘。大面积光焰使用能保留颜色的透明叠合，少量亮点再采用更亮的混合。Bloom 只加柔光晕，不能代替火焰形状；Bloom 的作用是在亮区边缘扩散光晕。[Unity Bloom](https://docs.unity3d.com/6000.0/Documentation/Manual/urp/post-processing-bloom.html)

如需精灵照亮附近台阶，建议单独配置一个小范围的随行 Point Light，并控制强度和阴影成本。谜题所用的光线、反射与吞光判定继续由游戏逻辑计算。

以后做“化光形态”时，可以用同一个进度驱动主体溶解、粒子增强与小光团显现，保留胸口光核作为视觉连续点。第一版不必让每个网格顶点都变成粒子；可先用几层效果交接完成。化光后的碰撞和通行能力需由玩法定义。

## 5. 已核验的 GitHub 源码

### NOVA Shader：第一版优先

[NOVA Shader](https://github.com/CyberAgentGameEntertainment/NovaShader) 是为 Particle System 提供的 URP 特效材质工具。README 要求 Unity 2022.3 LTS 或更高、URP、Shader Model 3.5；当前 package 为 3.6.0。已读许可为 MIT。

可使用流动贴图、Flipbook、溶解、发光和粒子拖尾相关功能。它提供材质工具，水彩外观仍需自己的贴图与颜色控制。按文档使用 NOVA 的 Flipbook 时，不要再同时使用 Particle System 的 Texture Sheet Animation；其具体纹理格式也应遵循对应模式。

[README](https://github.com/CyberAgentGameEntertainment/NovaShader/blob/main/README.md) · [package.json](https://github.com/CyberAgentGameEntertainment/NovaShader/blob/main/Assets/Nova/package.json) · [MIT 许可](https://github.com/CyberAgentGameEntertainment/NovaShader/blob/main/LICENSE.md)

### Unity Visual Effect Graph Samples：后续技术参考

[官方示例](https://github.com/Unity-Technologies/VisualEffectGraph-Samples) 中可参考 Bonfire 的火焰层次、Ribbon Pack 的光带与 Ellen Skinned Mesh 的蒙皮发射。

实查配置是 Unity 6000.0.23f1 + HDRP 17.0.3。它不是 URP 即插即用素材包。源码采用 Unity Companion License，另有第三方资源许可，不能把它表述为 MIT 包。需要对应版本的 VFX Graph 和渲染管线移植检查。

[样例介绍](https://github.com/Unity-Technologies/VisualEffectGraph-Samples/blob/master/README.md) · [Unity 版本](https://github.com/Unity-Technologies/VisualEffectGraph-Samples/blob/master/ProjectSettings/ProjectVersion.txt) · [HDRP 配置](https://github.com/Unity-Technologies/VisualEffectGraph-Samples/blob/master/Packages/manifest.json) · [许可](https://github.com/Unity-Technologies/VisualEffectGraph-Samples/blob/master/LICENSE.md)

### GPU-FlowField：需要复杂流场时再参考

[GPU-FlowField](https://github.com/Kodrin/GPU-FlowField) 是 MIT 许可的 Compute Shader 流场示例，可参考粒子随空间方向场漂移、回旋的算法。实际项目为 Unity 2019.4.1f1 + URP 7.3.1，属于旧版示例；不能保证整包直接迁移。

第一版使用 Particle System 的 Noise 和常规速度控制即可起步，之后需要大量光尘汇聚时再评估这个方向。

## 6. 建议实施顺序

1. 按基础三视图建立低复杂度模型和骨架，在真实正交关卡相机下确认头身比、行走和跳跃。
2. 完成身体水彩材质与面部可读性，再加胸口发光。
3. 加上后脑光焰薄片和局部流动材质，检查所有观察方向。
4. 加世界空间星尘和背部短拖尾，检查走、停、急转、跳跃、传送。
5. 最后加入弱 Bloom、少量随行照明与化光过渡，检查透明遮挡、墙体穿透及性能。

当前完成的是方案、源码核验与两张图。尚未进行模型导出、Unity 导入或运行验证。
