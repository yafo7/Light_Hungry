# 第三关 Unity 工程：排水暗渠 v05

Unity 2021.3.42f1c1；场景为 `Assets/Scenes/ThirdDrain.unity`。本版用完整可玩关卡替换旧入口预览，前两关与第三关共同包含在 Windows 构建中。

## 打开与试玩

- 工作区根目录 `试玩第三关.cmd`：直接开始第三关。
- `打开第三关工程.cmd`：用已安装的 Unity 编辑器打开本工程和第三关场景。
- `开始试玩.cmd` / `试玩前三关.cmd`：从第一关开始，依次进入第二关和第三关。
- `试玩第二关.cmd`：从陶盆开始，经阴影接触触发器进入完整第三关。
- 可执行文件：`../Builds/Windows-Level03/LightFeast.exe`；支持 `--level02`、`--level03` 直接进入指定关卡。
- 编辑器菜单：`食光兽/搭建第三关：排水暗渠` 和 `食光兽/构建第三关 Windows 试玩`。

## 操作

| 输入 | 行为 |
| --- | --- |
| A / D 或左右方向键 | 行走；化光后沿有效光路前后移动 |
| 空格 | 跳跃；开场时跳过全景收近 |
| E | 触碰根结；握住或松开附近绞盘；光态下请求安全恢复 |
| W / S 或上下方向键 | 握住绞盘时升降镜片，松开后保持位置 |
| Tab | 全景 / 游玩镜头 |
| R | 从第三关开头重新开始，重置本关进度 |

操作绞盘时镜头自动局部拉远，让球茎、反光片和配重同时可见；离开绞盘后恢复跟随。周围根须使用摄像机子物体，始终固定在单个视口上，全景查看时隐藏。

## 完整流程

1. 沿入口的苔阶接近根结，按 E 唤醒地下荧光球茎。
2. 跳到左岸绞盘，按 E 握住。W / S 控制镜架上升或下降，配重踏板反向移动。找到配重接近两岸的中位，再按 E 松开。
3. 借配重过水，登上对岸的绞盘台。直接跨越水面无法到达对岸，初始高悬的配重也不能直接跳上。
4. 在右岸继续升镜，让水平光线穿过中央墙孔，停留两秒唤醒远端光鳞。中低位光线会被墙柱挡住；墙孔不改变方向。
5. 从上层操作台右端下到低处，向右走，再依次跳上错层台阶；中途折返向左上，随后再向右上。悬臂台面使用单向平台，允许从下方起跳穿过台面。
6. 经过上层宽台到达水轮前，等移动踏板靠近后跳上。松开移动键会随台面移动，靠近对岸后跳离，再完成三次末段落点。
7. 到达光鳞下方的安全台面，且光线仍通过孔洞照到光鳞，显示第三关完成。没有接入尚未制作的第四关。

## 场景与实现

2026-11-02 柔光精灵风格实装：`Spirit.shader` 保留原水彩贴图，使用浅色映射与低对比明暗色带，叠加金白细轮廓和两层外扩光晕，充能时加强。它是对 D 版概念图方向的实时材质实现，保留原有三维模型。

`WickFlameTrail` 在后脑附近生成向后、向上飘散的金白火苗，并保留原有细光粒子；粒子在世界空间中自然消散，跟随角色朝向更新出生位置。化光时清空火焰，恢复后重新发射，重生位移不会留下跨场景长拖尾。`Assets/Resources/SpiritFlame.mat` 确保运行版包含火焰 Shader。近景录像位于 `../Validation/spirit-luminous-v01-2026-11-02/`，不改变正式游戏的镜头比例。

2026-11-02 骨架实装：共享 `WickSpirit.prefab` 已换为 22 骨骼 / 99,442 三角面的 SkinnedMeshRenderer。`Assets/Models/Rigged/WickSpirit_Game.fbx` 包含 Idle、Walk、Airborne 三个基础动作；Generic Animator 用 Move 与 Grounded 切换，关闭 Root Motion。`WickRigAnimation` 读取原 PlayerMotor 输入，不改变行走速度、跳跃轨迹或碰撞体。旧着色器的脚部顶点摆动对骨架角色禁用，充能描边与发尾粒子保留。

三个关卡共用此角色。骨架 FBX 朝向在预制体内转回项目原有 +X 前向，并统一为 1H 高度。近景实录使用独立 QA 相机，不改变正常游玩镜头。`../Tools/export-spirit-game-animation.py` 可从绑定版 Blender 文件重新导出基础动作；`WickRigSetup.Prepare` 负责导入与预制体接入。当前动作是初步效果，尚未精修脚底锁定、落地缓冲和机关操作手势。

- `01_Background_World`：水彩背景卡片，无行走碰撞。
- `02_Water_Animated`：独立水面、瀑布、微弱水纹扰动；前水面覆盖入水部分。
- `03_WalkableTerrain_XY`：跳台美术卡片与 BoxCollider2D / PlatformEffector2D。
- `04_Mechanisms_Independent`：球茎、根结、两只绞盘、同一个反光片和配重、摆渡踏板、水轮。
- `05_LightPath_AndScale`：同一折线路径负责显示和全局化光；墙孔的光学碰撞与受光目标；鳞片呼吸与粒子。
- `WickSpirit_Player`：沿用用户提供模型生成的 `WickSpirit.prefab`，保持 1H 高度与 2D 物理，保留发尾粒子。
- `Main Camera/06_CameraFixed_RootFrame`：固定视口根须。
- `ThirdDrain_FullLevel`：输入、教学提示、恢复点、完成条件和重开。

前景使用美术平面加真实 2D 碰撞，主角使用 3D 模型；相机正交且垂直于 XY 平面。当前不是把整幅图当作一个不可交互的背景。

## 数值和美术到玩法的调整

2026-11-02 可读性更新：独立交互道具使用 `InteractablePaint` 的淡白轮廓光，绳索使用随节点同步的白色柔光层。食光兽使用 `BeastScale`，身体保持浅白，中央目标鳞片单独控制灰暗到受光的颜色，不再把整片身体调暗。`DrainMechanism` 的受光时间与通关条件保持不变。

灯芯精灵原始模型为 1,988,934 三角面；项目现有运行模型已为 99,446 三角面 / 59,639 顶点，本次核对 Unity Mesh 与 Prefab 引用后保留这一版本，避免重复减面。单独交付至桌面 `食光兽/美术/灯芯精灵_99446三角面.glb`；原始模型不覆盖。核验与哈希见 `../Validation/model-budget-2026-11-02.json`。

2026-11-02 滑轮与流水更新：按用户红圈改为五个定滑轮，中心像素坐标为 `(404,112)`、`(521,112)`、`(663,112)`、`(696,112)`、`(918,112)`；旧的两个滑轮与配重上方中间横绳已移除。绳索按圆弧绕过轮缘，轮子随升降量转动。修改只涉及呈现，配重、光路和跳台的玩法参数保持原值。

`DrainWater.shader` 为独立水层实现连续动画：水面双向波纹与反光起伏，小瀑布向下输送水纹，落水点扩散涟漪；固定原画透明轮廓，避免瀑布口随纹理漂移。两层水仍分别位于平台后方和入水边缘前方。材质的 `Surface wave amplitude in source pixels` 和 `Downstream waterfall speed` 可调节水面幅度、瀑布速度。

2026-11-02 装配修正：移除纵向拉伸的整幅导架，使用保持长宽比的独立圆形滑轮、墙面固定件和细吊绳；反光片缩小并贴合墙柱导轨，重新对齐光束与斜面；两岸绞盘按实际透明轮廓贴住台面，吊绳末端接入配重吊环。原 v04 网页中的巨大导架为历史装配示意，以修正后的 Unity 场景为准。

角色仍为 1 世界单位高。本关映射为 `(x / 28, (542 - y) / 28)`，总长度约 77.5H。跳跃速度 13.5、水平速度 6、重力倍率 3；这些是第三关的原型调校，未修改前两关的序列化移动参数。

同一镜架和配重满足 `镜片中心的像素Y + 配重台面的像素Y = 740`：初始为 `425 / 315`，中位 `320 / 420`，高位 `215 / 525`。W / S 连续调整，接近中位时松手会落入小范围定位。两岸绞盘都控制这同一状态。

按照真实跳跃轨迹补了一块 B 段折返台，并把末段宽石台拆成三次可落脚的跳跃；采用原图 UV 切片重组，没有重新编码绘制素材。每一跳经过原生 Player 验证。道具导轨和绳索没有行走碰撞，不能作为隐藏的横桥。

恢复点设在入口、左岸、右岸、B 上层和水轮前。落水恢复到最新已落稳的恢复点，保留球茎开关和镜架高度。R 则重置整个第三关。角色站上摆渡台后获得平台横向速度，空中保持角色自身方向控制。

高位光束位于主要跳台上方，正常站立路线不能直接借它跳过 B/C；没有禁用全局化光组件。可见光线与 LightPath 节点一致，且受真实墙孔的光学碰撞限制。已唤醒光鳞会保留生命反馈，但完成关卡仍要求当前光路对准。
