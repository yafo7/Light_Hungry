# 第二关 Unity 原型：倒扣陶盆

## 打开与试玩

- 工程：本目录，Unity 2021.3.42f1c1。
- 场景：`Assets/Scenes/SecondLight.unity`。
- 工作区根目录的 `试玩第二关.cmd` 直接进入第二关。
- `开始试玩.cmd` / `试玩第一至第三关入口.cmd` 从第一关开始，完成尾鳞谜题后按 E 进入陶盆。
- Windows 构建：`../Builds/Windows-Level02/LightFeast.exe`；命令行 `--level02` 可直接进入第二关。

## 操作与流程

1. 开场从全景收近到行走区域；空格跳过开场，Tab 切换全景。
2. A / D 或左右方向键移动，空格跳跃。走到露珠出射光与身体相交的位置。
3. 站定受光三秒：身体边缘亮起、光晕扩大，最后收拢成一颗光粒子。移动、跳跃或离开有效光会打断这次蓄光。
4. 光态 A / D 沿同一条光路前后移动，松键停止。光核保留小圆形碰撞，不会无条件穿透石头。
5. 沿石缝抵达安全落脚台时自动恢复实体。E 也可请求在附近有安全地面和完整身体净空的位置恢复，石缝中不会强制恢复。
6. **接触右下角的阴影即切换到 `ThirdDrain`，不需要按 E。** 阴影用有柔软边缘的实时材质遮住原来下行石阶与远端通道。
7. R 重来；在第三关入口预览中按 R 返回第二关。

第二关没有食光兽身体，也没有重新调叶或调镜的步骤。叶片上的露珠预先把光送向缝口。碎石保持阻挡，不会在通过后消失。

## 场景结构

- `01_Background_NoCollision`：水彩陶盆和后壁，纯背景。
- `02_WalkableTerrain`：地面美术、简化地面碰撞、盆壁碰撞。
- `03_LeafAndRubble`：叶片露珠、堵住低处洞口的上下乱石堆；没有高耸的补充巨石。
- `04_RefractionAndShadow`：同源光路、实时光线、浮尘、缝后恢复点、阴影与接触触发器。
- `WickSpirit_Player`：用户提供模型生成的 3D Prefab，Rigidbody2D 和实体/光态两套碰撞。
- `05_Level02Flow`：教学提示、相机和输入。

角色高度仍为 1 个世界单位。美术注册按 v08 的 63 px / 角色高度及定位矩阵转换。顶点映射为 `(x / 63, (571 - y) / 63)`，摄像机垂直于 XY 平面。进入游玩镜头只改变相机取景，不改变角色、道具之间的比例。

## 从美术到可玩关卡的调整

v10 根据用户反馈撤掉 v09 额外叠加的高耸岩块，原来的大石板也替换成许多小石块、碎砖和少量陶片。石堆贴着右下洞口堆积，配色为与泥土、盆壁接近的暖灰褐色。盆沿、洞口上方的砖壁和堆积物共同围住暗渠，碰撞按这段结构衔接，不再依靠高石塔封路。

新乱石保留真实透明缝隙；沿其校准光路为源图像素 `y = 0.519x + 60`，注册到场景后为 `y = 0.519x + 5.326`。光线显示、光态移动和窄缝碰撞使用同一条线路。

右下通道以原生 `PassageShadow` 材质覆盖，带轻微流动边缘。触发范围位于可见阴影内部，而非整块矩形贴片的透明边缘。

## 可复用能力与实现范围

`LightFormAbility` 已接入第一关和第二关的主角，不是第二关才解锁的专用开关。`LightPath` 同时提供显示、受光检测和光态位移的数据；第一关读取现有镜面反射线，第二关采用固定露珠出射路线。

当前露珠路线是经过碰撞校准的关卡导线，**不是求解任意水滴曲面折射的光学模拟**。叶片露珠目前作为组合美术件，没有单独的水滴着色器。自动安全恢复、移动中断蓄光等为本版可玩原型采用的操作规则，后续仍可调整。

第三关已在 v05 中升级为完整可玩的排水暗渠，包含一个共享升降反光片、配重过闸、折返跳台和水轮摆渡；当前启动脚本使用 `Builds/Windows-Level03/LightFeast.exe`，第二关阴影入口会进入完整第三关。详见 [第三关说明](LEVEL03_README.md)。旧 `Windows-Level02` 构建保留为历史版本，仍只有第三关入口预览。

## 构建与验证

`../Tools/Build-SecondLight.ps1 -Validate` 可构建并执行原生测试。主工程在编辑器中打开时，脚本使用 `.build-level02` 副本编译，随后将生成场景和资源同步回来；不会关闭原编辑器。

2026-10-30 最终构建：0 个构建错误、0 个构建警告。原生第二关测试 21/21 通过；第一关至第二关的实际场景切换另行通过。报告为 `../Validation/level02/native-run/playthrough.json` 与 `../Validation/level02/level-link/first-to-second.json`。同目录保存实际渲染截图；其余 `verified-*` 等目录为中间验证，不代表最终画面。

测试通过与否以 JSON 报告为准。原生截图由 Windows Player 的 Direct3D 11 相机渲染到 RenderTexture，包含实际场景与角色效果，不包含 IMGUI 教学界面；这不是静态设计图，也不替代人工手感评估。
